# Silver knight R7 — MakeHuman + Blender static armor revision

Requested changes: slender human silver knight, thin sloping shoulder plates,
longer-looking slim arms, flatter waist/tassets, retained helmet, matching the
original sprite's direction, and a grounded stance without inward-pointing feet.
This is a static candidate for review. No animation clips were made or changed.

## Editable sources and production

`knight.mhm` stores the human phenotype, `knight-human.json` stores the MPFB
human/rig preset. The added eyes and all armor are generated by
`tools/knight3d/silver_knight_armor.py`; the native presets only describe the
human foundation. `build_makehuman.py --revision 7` uses a distinct output
folder, leaving R4/R5/R6 delivered candidates unchanged.

`knight_makehuman.blend` contains the complete hidden MakeHuman source with
shape keys, its standard 53-bone rig, separate editable armor, human face and
eyes, static pose and studio. `knight_makehuman.glb` is the visible posed mesh
baked for static inspection, with one material and two packed 40×4 palette maps.
It has no skin or animation and is not the final playable animated asset.

R7 lowers the MakeHuman muscle/weight settings, replaces shoulder balls/rings
with shallow sloping shells, uses open tapered arm plates over actual anatomy,
replaces waist rings and pouches with a close lower plate, belt and two flat
tassets, and retains an open silver helmet over the real human face.

The stance is a diagonal step: sword-side rear foot externally rotated 60°,
other foot 8°. Thigh/calf facing follows the same toe direction. Validation
uses the actual modeled shoe heel/toe points transformed by the saved skeleton,
including outward direction, forward direction, knee/toe agreement and sole
height. This avoids relying on just Euler values or a mirrored preview.

## Comparison and scope

The source is the unchanged SE idle first frame. The 3D camera is moved to the
matching front-right view; neither image is horizontally mirrored. Its screen
projection of character-forward must point right, and the front foot must
project below the rear foot, matching the source arrangement.

All views are rendered after reopening the delivered Blend. The main sheet
matches each character's head-to-foot height to 500px with one uniform scale.
The supplemental feet, upper body and front/side/back views allow shape review.
The 56px sheet is a game-size estimate, not a live game screenshot. Footprint
shadows are presentation-only and use the projected floor-level heel/toe points.

This package can be merged for preservation/review. Similarity and style still
require visual acceptance; six animations, final articulation, game replacement
and live GPU performance remain outside this static revision.
