# Skills2 範圍格式 v2

## 填寫

每個欄位各自表達一種用途，不再使用含義不定的 `range`／作用距離欄。

| 格式 | 意義 |
| --- | --- |
| `6` | 範圍欄：圓形半徑6米；距離欄：線性距離6米，無等級增量 |
| `6,1` | 半徑／距離底值6，每級增加1 |
| `10 * 10 , 1 * 1` | 矩形長寬底值各10，每級各增加1 |
| `20*5,2*0.5` | 長度底值20、每級+2；寬度底值5、每級+0.5 |
| 空白 | 本列沒有設定；依技能既有繼承或單體規則處理，不能解讀為0 |

沿用既有公式 `基值＋每級增量×等級`：`6,1` 在 Lv.1 為7、Lv.10為16。
逗號使用半形`,`，矩形使用`*`，允許空格。禁止半套矩形增量、額外逗號、NaN、Infinity及升級後負範圍。

## 用途

| 欄位 | 唯一用途 |
| --- | --- |
| 施放距離 | 玩家與起手目標的距離門檻 |
| 搜敵範圍 | 隨機目標、分裂、彈射與追蹤的搜尋半徑 |
| 傷害範圍 | 一次群體傷害的圓形半徑或矩形長寬 |
| 狀態／控制範圍 | 暈眩、狀態附加、吸引及水牢等控制判定 |
| 觸發偵測範圍 | 觀察死亡、受傷或燃燒事件，供被動效果計數 |
| 碰撞體尺寸 | 投射物／環繞物本身接觸敵人的長寬；不是環繞半徑 |
| 環繞半徑 | 環繞路徑的半徑／螺旋最大半徑（依該階機制） |
| 飛行距離 | 刀波或投射物向外推進的距離 |
| 貫穿追加距離 | 在基礎貫穿長度上額外相加的距離 |
| 生成／環間間距 | 母體與伴生物的間隙，或內外環的間距 |
| 每次施放追加半徑 | 每次連續施放增加的半徑，不是等級增量 |
| 游走範圍 | 火龍捲隨機移動可達的半徑 |
| 生成位置範圍 | 生成點的矩形配置（例如水龍捲四角），不控制傷害 |
| 拋物線高度 | 水彈離地弧高 |
| 每秒半徑擴張 | 虛空斬環繞半徑每秒增加量 |
| 光幕寬度 | 雷幕掃過的帶寬，長度由場地邊界決定 |

間隔、發射夾角、飛行速度及範圍百分比也合併為`基值,每級增量`。發射夾角描述箭道／刀道，不是扇形傷害區域。
每列的中心、方向、目標數及觸發時間仍由「作用方式與距離用途」描述該技能規則。

例：爆散只填搜敵範圍12；霹靂一閃分別填搜敵範圍與傷害100*10；風刃分別填施放30、飛行80、碰撞4*8。實際數值以Excel目前設定為準。
搜敵範圍不能作為單體特效縮放依據；原傷害範圍與特效同步規範不變。

## 判定與接線

此遷移不將每個技能改成可任意切換形狀。現有圓形技能填半徑，矩形技能填長*寬；未接線的欄或不符判定形狀會明確拒絕匯入，不能靜默忽略。
環繞物原有等徑碰撞（例如虛空斬圓盤）的長寬必須相同。沼澤、暴風雪、水龍捲生成位置支援獨立長寬。

`tools/skills2-geometry.cjs` 是欄位與技能階段接線的唯一來源。新版輸入轉譯為既有模擬參數，`m` 等內部鍵保留相容，不能再透過JSON重複編輯。
`sgGeometryNumber` 補足原先只讀底值的路徑，依所屬階段讀取目前等級；已結算的場域／事件副本不會再增加一次。沒有每級增量時走直接讀值快路徑。

## Excel 保存

遷移由 `tools/migrate-skills2-geometry.cjs` 讀取官方Excel，產生資料JSON，再由 `tools/write-skills2-excel.ps1` 使用Excel COM API寫入副本並正常重開逐格驗證。驗證前不替換原檔，來源hash改變則停止，避免覆盖使用者新存檔。
Skills2 的 `--gen` 也使用此原生Excel流程，禁止手工拼接／替換工作簿XML。CSV↔JS沿用 `tools/config_tables.cjs --sync`／`--apply Skills2 --write`。

舊空白繪圖物件另由 `-RemoveBlankArtifacts` 清理：確認可見物件皆為空白後，以Excel API複製儲存格至乾淨工作簿且禁止複製繪圖物件，再連續儲存／正常重開確認物件數為零。一般寫入不自動啟用清理。

驗證：`node --test tests/skills2-geometry.test.cjs`；測試包含解析、用途分離、資料往返、等級成長與獨立矩形長寬。
