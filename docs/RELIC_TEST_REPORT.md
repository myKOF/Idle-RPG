## 觀察（不是缺陷，供設計參考）

1. **星圖殘頁的經驗量。** 測試存檔是 Lv.50 但封魔塔已到第 100 層（之前 GM 跳層），一次 `offline` 拿到 34 次第 100 層 BOSS 獎勵後角色升到 Lv.1000（上限）。
   正常進度的玩家等級會跟得上塔層，所以不是缺陷；但它確實是「每 N 小時一次最高層 BOSS 的完整獎勵（含經驗）」，滿級 34 小時離線＝34 場 BOSS。數值若嫌高，調「數值強度」欄即可。
2. **晨鐘不會因 `relic reset` 消失。** 加成是離線結算當下給的限時效果，拿掉遺物後時間到才結束。合理，但測試時要記得它還掛著。
3. **晨鐘時間會被覆蓋而不是累加。** 加成中再結算一次離線，到期時間改成「現在＋本級分鐘數」。同等級下只會延長，不會變短。
4. **洗煉精華的折扣向下取整。** 精華數小（例如 12）時實際折扣比標示多一點（−16.7%）。對玩家有利，影響很小。
