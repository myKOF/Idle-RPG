# AIR-VFX-20260922：飛行特效透視保形

## 原因與完成內容

原先 BattleRenderer 把場景（含 presetFx 與 legacy fx）先畫到 RenderTexture，再整片經 PerspectiveMesh 做單應投影。不同位置的 X/Y 放大率及剪切量不同，圓形星環在邊緣會歪斜。這是共用場景後製造成，不是單一星環貼圖的問題。

新增 stage 空中層，位於场景上、傷害字／玩家 HUD 下；空中物件只投影錨點，X/Y 同乘該深度的比例，保留素材自己設定的旋轉、非等比尺寸及動畫。位置仍沿權威路徑／地面座標投影，未改碰撞、飛行速度、編隊半徑、旋轉或傷害。

Runtime 的空中 Core／Backend 處理飛行物，逐幀投影全部 sprite、sheet 與尾焰粒子。註冊、更新、clear、尾焰結束及 destroy 都包含空中 Runtime；無專用後端的高塔／編輯器／既有測試維持原 fx 行為。Preset 與 legacy 使用獨立容器，避免後端 destroy 清掉其他物件。
