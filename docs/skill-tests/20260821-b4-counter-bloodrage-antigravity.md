## 1. 測試環境與設定規範

### 1.1 角色屬性與裝備配置
* **裝備等級與強化**：
  * 全身 13 格裝備全數為 **100 級傳奇（Legendary）**。
  * 強化等級：**+40**（詞條屬性乘數為 $1 + 40 \times 0.05 = 3.0\times$）。
  * 專屬武器配置：
    * 反擊（`counter`）：主手單手劍 (`sword1h`) + 副手盾牌 (`shield`)。
    * 嗜血狂怒（`bloodrage`）：雙手大劍 (`greatsword2h`)。
* **技能等級設定**：
  * **未點超神進化組（對照組）**：第 1~7 階技能全數升至 Lv.10（滿級），超神進化欄位為空（No Ult）。
  * **超神進化組（實驗組）**：第 1~7 階技能全數升至 Lv.10（滿級），超神進化第 8 階升至 Lv.10（滿級）。

### 1.2 機制專屬裝備詞條適配
* **反擊（Counter）**：
  * `神聖之體`：配置 `blockRate`（格擋率）+ `aoeDmg`（範圍傷）+ `atkPct` + `critDmg` + `pPen`。
  * `不屈鬥魂`：配置 `hpPct`（生命上限）+ `atkPct`（攻擊%）+ `blockRate` + `critDmg` + `pPen`。
  * `戰神體`：配置 `hpPct` + `atkPct` + `blockRate` + `critDmg` + `pPen`。
* **嗜血狂怒（Bloodrage）**：
  * `殺神降臨`：配置 `aspd`（攻擊速度）+ `aoeDmg`（範圍傷）+ `atkPct` + `critDmg` + `pPen`。
  * `戰神屠錄`：配置 `atkPct` + `critDmg` + `pPen` + `cdr` + `hit`。
  * `阿修羅霸王拳`：配置 `atkPct` + `critDmg` + `pPen` + `cdr` + `aoeDmg`。

### 1.3 測試地圖與三種波次情境（100 級冰原 Icefield）
* **場景 1（小怪群戰）**：小怪 20 隻/波，每 2.0 秒出 1 波，連續出 10 波（共計 **200 隻**；單隻 HP ~1,296,000 / DEF 6,496）。
* **場景 2（菁英攻堅）**：菁英怪 5 隻/波，每 2.0 秒出 1 波，連續出 5 波（共計 **25 隻**；單隻 HP ~5,185,000 / DEF 6,496）。
* **場景 3（單體 BOSS）**：1 隻 BOSS（HP **~19,446,000** / DEF 12,992）。

## 4. 關鍵機制與平衡性亮點評析

1. **反擊群組的機制質變**：
   - **戰神體（War God Body）**：展現了極高的乘區潛力。由於高難度關卡中敵人攻擊強度高，角色承受失血量大，失血 % 轉化為反擊傷害後，單體 BOSS 輸出達到 **3.11B DPS（+874% 成長）**，是防禦反擊流派的核心輸出支柱。
   - **不屈鬥魂（Indomitable）**：作為全專案第二道死亡攔截機制（天地共生 → 不屈鬥魂 → 不屈之誓），其死亡時釋放的 4000% 地系爆發能直接將對手擊斃，倒地 5 秒期間鎖血 1 點且禁止行動，提供卓越的容錯率。

2. **嗜血狂怒群組的爆發特性**：
   - **戰神屠錄（War God Roll）**：在小怪波次串流中展現出頂級的滾雪球能力。雖然代價是狂怒期間無法獲得任何護盾，但擊殺疊層增傷持續至死亡，小怪戰輸出由 2.26B 躍升至 **5.85B DPS**（峰值達 22.13B）。
   - **阿修羅霸王拳（Asura Fist）**：每 10 秒固定獲得 2 秒全傷害 +1000% 爆發窗口，在 BOSS 與菁英戰中均能打出極其可觀的週期峰值（高達 27.02B）。
