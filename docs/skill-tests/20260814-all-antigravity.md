## 4. 建議追蹤與數值觀察

1. **雙刀亂舞 (dualdance) 狂暴暴風高密度爆發**：
   - 雙刀亂舞全滿檔位在多目標（如小怪 12~20 隻）時，由於第 7 階暴風之舞每 0.35 秒自動觸發 1 次雙刀亂舞，加上第 5/6 階血量與流血機制疊加，DPS 隨敵人數量呈極高次方爆發（小怪 20 隻達到 ~2.58M DPS）。此屬設計預期之群體爆發型特色，數值表現亮眼，可供企劃調教參考。
2. **專屬特效 (VFX) 辨識度良好**：
   - 6 個技能群組皆有獨立 `variant`（`thrust` / `cleave` / `knife` / `gale` / `bloodblade` / `dualdance`），戰鬥畫面可清晰分辨。
