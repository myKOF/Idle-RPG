## 4. 建議追蹤與數值觀察

1. **純技能 DPS 分化與特性明顯**：
   - 排除普攻後，單體 BOSS 戰中各技能表現出明確差異：如 `dualdance` 全滿 459k DPS > `bloodblade` 370k DPS > `gale` 368k DPS > `thrust` 363k DPS > `knife` 360k DPS > `cleave` 213k DPS。
   - 多敵（小怪 20 隻）情境下：`dualdance`（~993k）與 `bloodblade`（~638k）呈現強烈的多目標群體擴散/DoT感染能力；`knife`（~529k）憑藉彈射鏈展現優異清怪效率；`thrust`（~315k）、`gale`（~271k）、`cleave`（~237k）則受限於近戰線段與目標數封頂。
2. **專屬特效 (VFX) 辨識度良好**：
   - 6 個技能群組皆有獨立 `variant`（`thrust` / `cleave` / `knife` / `gale` / `bloodblade` / `dualdance`），戰鬥畫面可清晰分辨。
