# CHAIN-ASPECT-20260929：飛行雷鏈保形縮放

## 原因與完成內容

飛行雷鏈把 542.464 的製作長度縮成 180 世界單位，但縱向仍固定角色倍率；貼圖內建折線和額外變形都因此變陡，降低 deformation.amplitude 只能處理其中一部分。

起飛、逐幀追蹤及抵達收尾現在以相同 X／Y 比例縮放，維持編輯器的形狀比例。包含斜俯視方向修正，不會在追蹤轉向時重新壓陡。18 米長度、速度、命中時間、尖端裁切與回收不變，無飛行時間的靜態連線維持舊行為。

這會同時等比縮小貼圖內的電光粗細，而非只消除新增彎曲。使用者目前調整的振幅、頻率、色彩與圖層資料全部保留；沒有修改 Preset 或配置表。
