## 3. 技能特性與平衡分析

1. **單體輸出（1 隻 BOSS / 菁英）**：
   - 火龍捲（全滿 75k~85k DPS）> 火狩（全滿 68k~78k DPS）> 火球術（全滿 40k~43k DPS）。
   - 火龍捲的多段打擊特性在單體定點目標上能快速疊加高頻傷害。
2. **多目標輸出（12~20 隻小怪）**：
   - 火狩（全滿 880k~963k DPS）> 火球術（全滿 292k~658k DPS）> 火龍捲（全滿 255k~597k DPS）。
   - **火狩**作為環繞近身持續場域，在怪群包圍時，多顆旋轉火球能同時刮過四周所有敵人，伴生體與雙圈反向旋轉（狩神之舞）對包圍圈形成極高密度的連續掃蕩。
   - **火球術**靠火球爆裂（分裂 3 顆小火球）、殞石術（3 顆 15m 範圍）與爆燃引爆，群體爆發隨敵群密度顯著放大。
   - **火龍捲**在多敵時主要靠雙重龍捲與 3 道無限火牆覆蓋橫向走廊。
