* 重跑：`node tools/ult-dps-benchmark.cjs`，再執行`node tools/ult-dps-report.cjs`。工具不讀寫玩家存檔，不修改遊戲配置。
* 結構及算術驗證：`node --test tests/ult-dps-benchmark.test.cjs`；`node tools/ult-dps-report.cjs --check`比對報告與JSON是否一致。
