# 封魔塔 BOSS 玩家技能（2026-10-15）

> 本表由 `Skills2` 超神進化列的「解鎖轉生/等級/封魔塔層級」第三段自動衍生（`js/elite_data.js` bskFixedOptions），不是另一份獨立資料；Skills2 改了層級，BOSS 使用的技能跟著換。

## 規則

1. 某層 BOSS 解鎖哪個超神進化技能（Skills2 封魔塔層級＝該層），牠就**固定**使用哪個；同層解鎖兩個就兩個都用。
2. 技能的**效果參數、特效 Preset、狀態**都直接讀玩家那一列（最高等級 Lv.10），不另開一份數值；**傷害套 BOSS 攻擊力**：倍率＝技能 pct ÷ 100 × `psDmgPct`。
3. 沒有解鎖技能的 BOSS（第 1～18 層與其他沒有解鎖技能的層，到第 100 層為止）：**額外多抽 2 個 NPC 隨機技能**（在原本「專屬＋隨機 4~6 個」之上）。
4. **第 101 層起**每一場隨機抽 **2 個**玩家超神進化技能（69 個選項不重複抽籤），不再額外抽 NPC 隨機技能。
5. 隨機技能（NPC 隨機池、101 層起的玩家技能）**每次挑戰都重抽**；只有會解鎖玩家技能的 BOSS 是固定專屬技能。

## 為什麼不是「原封不動搬玩家技能」

玩家技能引擎（`js/skills2.js`）整套綁死「施法者＝玩家、目標＝敵群」，無法直接反向給單一 BOSS 打單一玩家。
所以 BOSS 端把每個技能拆成同一組動作零件（齊射、直線、環形、落點、場域、環繞、領域、連鎖、增益），
零件重用 `js/elite.js` 的預警／傷害／場域／特效派送，招式的數值與特效全部取自玩家那一列。
特效 Preset 沒有任何寫死：預警圈取自敵人技能表同屬性的落點預警，其餘全取自 Skills2 該列（含觸發欄）。
玩家技能為了「打一群怪」設計的多段／多落點，打在單一玩家身上會爆量，因此同一次施放對同一玩家的第 N 下傷害遞減，範圍半徑乘 `psAreaPct`。

## 調整旋鈕

| 旋鈕 | 預設 | 作用 |
|---|---|---|
| `ELITE_GROUP.psDmgPct` | 25 | 技能傷害倍率：技能 pct%→BOSS 攻擊倍率 |
| `ELITE_GROUP.psTickPct` | 20 | 持續場域／領域跳動傷害的再折扣 |
| `ELITE_GROUP.psAreaPct` | 60 | 範圍半徑倍率（玩家技能範圍是為群怪設計的） |
| `ELITE_GROUP.psBuffPct` | 25 | 玩家式增益（攻擊提高％、疊層）轉成 BOSS 增益的強度 |
| `ELITE_GROUP.psCtrlPct` | 50 | 控場（暈眩／緩速）秒數倍率 |
| `ELITE_GROUP.psShieldPct` | 15 | 護盾量倍率 |
| `ELITE_GROUP.psReviveHpPct` | 40 | 復活技能的復活生命倍率 |
| `ELITE_GROUP.psPassiveGap` | 4 | 被動反應技能兩次觸發的最短間隔（秒） |
| Skills2 該列效果參數 `bossMul` | 1 | 單一技能給 BOSS 用時的傷害倍率 |
| Skills2 該列效果參數 `bossCd`／`bossCdMax` | 空 | 單一技能給 BOSS 用時的冷卻（秒） |

`ELITE_GROUP.ps*` 沒填就用上表預設；填法＝參數表「4-菁英群組／菁英技能全域設定」或直接改 `js/data.js` ELITE_GROUP。

## 建議驗證（Antigravity）

- 以 GM `tower_jump N` 跳層後挑戰：N＝上表任一層，確認 BOSS 血條下方技能標籤含該層技能，且戰鬥中施放時頭上浮出技能名。
- 以 GM `elite 1 ps_<技能id> 1 1000000 boss` 在演武場單獨觀察每個技能的預警圈／特效／傷害（`elite list` 可列出全部 ps_ id）。
- 確認第 1 層與其他無解鎖層 BOSS 的技能標籤比以前多 2 個隨機技能；第 101、102…層每次挑戰的玩家技能標籤不同。
- 被動型（神聖之體、不屈鬥魂、天地再造、逆轉乾坤、天穹崩裂）：不屈鬥魂／天地再造／逆轉乾坤致命傷時戰鬥不結束；神聖之體／天穹崩裂在 BOSS 連續受擊後會反擊。
- 環繞型（烈陽星環、無限星環、臨界雷劫、虛空滅界、時空崩解、森羅萬象）：環繞體圍著 BOSS 轉，碰到玩家才有傷害數字；BOSS 離玩家較遠時會先衝近再出招。
- Console 無新增錯誤；施放大量技能時 FPS 沒有明顯崩落（VFX Runtime 的 skipped／missing 維持 0）。
