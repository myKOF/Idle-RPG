# 符文與符文真言平衡性統計報告

> **統計規則說明**：
> 1. 全數以提供該屬性的**最高級符文／符文真言**計算部位極大值；若受裝備子部位限制或同名不可疊加限制，則自動以次高級可同時裝備之符文真言遞補統計。
> 2. **極大值欄位格式**：`×總倍率（Lv100神鑄混沌面板值）`；固定百分比機制則直接顯示 `+N%`。
> 3. **共有幾個符文用到**：列出資料庫中「共有幾種符文（或幾組真言）具備此屬性」，並於括號標註「湊出該極大值實際鑲嵌的顆數／裝備件數」。
