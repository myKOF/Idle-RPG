## 3. 符文真言（65 組）

「效果（預期）」的屬性行已用參考裝備算好實際數值；機制行（被動、事件觸發、傳奇特效…）是遊戲內顯示的文字。真言屬性**不乘雙手倍率**，所以雙手武器上的屬性行數字與單手相同。
「最低品質」＝剛好放得下這組配方的最低裝備稀有度；「—」＝該類裝備做不出這組（例如 5 顆真言只給雙手武器，防具類真言沒有雙手武器版）。孔數隨「表-稀有度」的設定改變，這張表會跟著重產。
