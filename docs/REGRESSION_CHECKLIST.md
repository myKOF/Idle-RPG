# P3 UI 去狀態化迴歸測試清單 (Regression Checklist)

> **目的**：本清單為 P3 階段 `js/ui.js` 重構（將 16 處直寫 `G` 與 32 個變更呼叫改為 `send(cmd)` 協議）之全頁籤 UI 迴歸驗收標準。
> **適用對象**：Codex (P3 實作者)、Claude (Reviewer)、Antigravity (QA 驗證)。
> **建立日期**：2026-07-27

## 6. P3 驗收測試門檻 (Definition of Done for P3)

1. 上述 21 項測試案例在 `?worker=1` 模式下需 **100% 通過**。
2. 無新增 Console Error。
3. 連點操作無畫面卡死、指令遺失或數值倒退（Race Condition）。
4. 拖放與即時回饋延遲低於 50ms（符合 P0 基準線）。
