## 2. 環境與準備

- 打開 http://localhost:8331/，**先在 Console 執行 `GameSettings.set('mute', true)` 把遊戲全靜音**（AI_RULES 第 17 節），再進遊戲。
- 這個瀏覽器若沒有這個網址的存檔，直接按「新遊戲」建拋棄式存檔即可。
- GM 指令在 DevTools Console 執行（一次一行）：

```js
await WorkerBridge.send('gm.exec', { line: 'relic all 30' }).then(r => r.message)
```

- 常用 GM：

```text
relic 編號|all [數量]    給遺物件數（未解鎖自動解鎖 Lv.1）
relic max               全部直接滿級
relic reset             清空遺物
offline 小時             模擬離線（0.02～1000，可小數）
level 300 / gold 1e15 / scrap 1e12 / essence 1e9 / dust 1e6
invite 5                神祕邀請券 +5
tower_jump 11           第 1～10 層視為已通關
rune all 20 / gem all 5 100
equip 4 100 any 50      50 件 100 級史詩裝備
```

- 比較型測項的做法：先 `relic reset` 記下基準值，再 `relic max`（或指定那一件升到 Lv.10）記下新值。
