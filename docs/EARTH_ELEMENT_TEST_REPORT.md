## 2. 測試執行詳細記錄

### 2.1 岩甲護盾（Rock Armor）測試
- **GM 指令發送**：`level 1000` / `reincarnation 10` / `book earth 20` / `book dark 20` / `equip godforged 1000 weapon 3`
- **實測紀錄**：
  1. 武器附魔「磐岩附魔」並卸下技能僅留普攻。
  2. 命中敵方時戰鬥日誌輸出：`［岩甲］ 造成地屬性傷害 ...`，角色上方浮現 `🛡️+N`，玩家護盾條數值即時攀升。
  3. **觸發次數**：40 次普攻命中中觸發 11 次 (27.5%)。
  4. **對照組**：切換為「暗影附魔」時，普攻正常觸發汲取回復 (`+N HP`)；技能命中時，岩甲與暗影汲取皆不觸發，行為完全一致。
