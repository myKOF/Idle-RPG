# 菁英群組與菁英詞條（技能）

2026-10-07 起，菁英敵人改成「成群出現、每隻帶 1～3 個詞條技能」。這份文件是設計說明＋全部詞條的總表。

## 規則

1. **出現時機**
   - 菁英關（階段是 10 的倍數）：每一波補怪都是菁英群，**群數**沿用原本「4-敵人數量」的各張「菁英 數量權重」列（那幾列現在的意思是群數）。BOSS 關（每 50 階、沒打過的 BOSS）不變。
   - 普通關：每一波補怪有一定機率改成菁英群（群數看「普通關菁英群數量權重」），機率依「地圖 × 關卡區間」設定。
2. **群組**：每群 2～4 隻，**全員菁英**或**菁英帶小兵**（帶隊菁英數、小兵倍率見參數表）。同一群共用同一組詞條，小兵沒有詞條。同一群生在一起、一起進場，腳下有同色的群組環。
3. **詞條**：每隻菁英 1～3 個（機率看關卡區間）；同一個「互斥組」只會抽到一個；有些強力詞條有最低關卡。
4. **看得出他放了什麼**
   - 施放時頭上浮出「圖示＋技能名」，戰鬥日誌一行，自身一道施法光；
   - 會傷到你的範圍技能一律先在地上畫預警（紅圈＝物理／火、藍圈＝冰／雷、各色魔法陣…），倒數完才結算，離開範圍就躲掉；
   - 頭頂的詞條圖示列一直都在；護盾、無敵、反射、狂暴時腳下有對應顏色的光環；生命鏈結的成員之間有粉紅連線。
5. 全部特效都用 `vfx/presets/` 既有的 Preset，登記在 `docs/vfx/VFX_PRESET_USAGE_OUTSIDE_TABLES.md`（`菁英…` 開頭的列）。

## 怎麼調

| 想調什麼 | 去哪裡 |
|---|---|
| 普通關遇菁英群的機率（地圖 × 關卡區間） | `game_parameters` →「4-菁英群組」→ 普通關菁英機率(荒漠／冰原／沼澤／亡靈山脈／其他地圖) |
| 每群幾隻、各機率 | 同分類 → 群組成員數權重(各地圖)，格式 `{關卡下限~上限,隻數,權重}` |
| 全員菁英還是帶小兵 | 同分類 → 純菁英群機率(各地圖)；帶隊人數與小兵倍率見「混合群與小兵」 |
| 普通關一次出幾群 | 同分類 → 普通關菁英群數量權重；菁英關的群數見「4-敵人數量」的「菁英 數量權重」各列 |
| 每隻帶幾個技能 | 同分類 → 菁英技能數量權重 |
| 所有菁英技能的傷害／冷卻總倍率、場域與召喚上限 | 同分類 → 菁英技能全域設定 |
| 單一技能的冷卻、半徑、傷害倍率、持續時間 | `js/elite_data.js` 的 `ELITE_AFFIXES`（下面總表的「關鍵數字」） |
| 菁英本體的生命／攻擊倍率 | 原本的「4-野外怪物 → 菁英倍率」 |

改完 Excel 之後雙擊「套用參數.bat」。改了 `js/elite_data.js` 之後執行 `node tools/gen_elite_doc.cjs` 重生下面的總表。

## 在遊戲裡看某個技能

`elite list` 看全部詞條 id；`elite 1 meteor 2 1000000` 生成 1 群 2 隻、隕石雨、打不死的菁英，`spawn off` 收尾（見 `GM_command.md`）。

## 新增一個詞條

1. 在 `js/elite_data.js` 的 `ELITE_AFFIXES` 加一列（沿用既有的 `arch` 原型就不必改程式；新原型要在 `js/elite.js` 的 `ELITE_CASTERS` 或 `ELITE_PASSIVE_ARCHS` 登記）。
2. 用到的 preset 登記到 `docs/vfx/VFX_PRESET_USAGE_OUTSIDE_TABLES.md`。
3. 跑 `node tools/gen_elite_doc.cjs`，再跑 `node --test tests/elite-data.test.cjs`。
