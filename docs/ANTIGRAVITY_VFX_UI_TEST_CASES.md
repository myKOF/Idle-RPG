# Antigravity 測試用例：戰鬥特效與裝備操作延遲

## 測試目的

確認戰鬥特效降載後，裝備、洗煉、強化等操作能在戰鬥持續進行時保持可用；同時確認戰鬥數值、Worker 指令與存檔資料沒有受到視覺層調整影響。

本文件供 Antigravity 進行瀏覽器唯讀驗證。除非另有明確授權，請勿修改程式碼或測試資料。

## 測試環境與前置條件

- 使用本專案目前建置版本與瀏覽器測試服。
- 記錄瀏覽器版本、作業系統、CPU、GPU、螢幕解析度與是否開啟硬體加速。
- 使用可持續戰鬥的存檔，並準備至少一件可強化裝備及一件可洗煉裝備。
- 開啟瀏覽器 DevTools 的 Console；必要時開啟 Performance 面板記錄輸入事件與 Long Task。
- 戰鬥開始後，先確認目前位於「裝備」頁，再依案例切換到「爬塔／戰鬥」頁。

## 測試案例

### AG-VFX-001：頁籤品質分級

操作：

1. 開啟「裝備」頁，等待一個戰鬥週期。
2. 觀察命中、飛行物、爆炸與畫面震動等特效。
3. 切換至「爬塔／戰鬥」頁，重複觀察。
4. 在兩個頁籤間來回切換至少 5 次。

預期：

- 裝備、強化、洗煉等非戰鬥操作頁使用 Reduced 視覺效果：不出現持續性 Aura，粒子數明顯較少，普通命中不觸發畫面震動。
- 爬塔／戰鬥頁恢復完整特效。
- 切換頁籤不會造成頁面卡死、空白、重複 DOM 或 Console 錯誤。

### AG-VFX-002：戰鬥中洗煉裝備

操作：

1. 在「裝備」頁讓戰鬥持續並等待特效密集的時段。
2. 連續點擊同一件裝備的洗煉按鈕 5 次，每次等待結果回應後再點擊。
3. 觀察按鈕狀態、洗煉結果、資源扣除與戰鬥血量。

預期：

- 點擊後按鈕能正常進入處理狀態，結果回應後可再次操作。
- 不會因特效造成點擊無反應、重複扣除資源、重複套用結果或永久鎖定。
- 戰鬥仍持續更新；戰鬥數值與洗煉結果不因 Reduced 特效而改變。

### AG-VFX-003：戰鬥中強化裝備

操作：

1. 在戰鬥持續時，選擇一件可強化裝備。
2. 在命中特效密集的 10 秒內，依序強化 5 次；若可選不同裝備，至少切換 2 件。
3. 觀察強化等級、消耗資源、裝備面板與戰鬥畫面。

預期：

- 每次強化最多產生一次結果，等級與資源數量一致。
- 裝備面板不會因背景戰鬥更新而跳回舊資料或清空選取狀態。
- 點擊延遲應短暫且可恢復；不可出現需要重新整理頁面的狀況。

### AG-VFX-004：短時間特效爆量時的操作可靠性

操作：

1. 切換至「裝備」頁。
2. 觸發可造成連鎖、範圍或多目標命中的戰鬥情境。
3. 在 2 秒內交替執行：點選裝備、開啟詳情、關閉詳情、洗煉或強化。
4. 重複 3 回合。

預期：

- 特效可被合併或延後播放，但輸入操作不遺失。
- 不出現大量排隊特效導致幾秒以上的 UI 凍結。
- Console 沒有未捕捉例外、重複 listener 或 DOM 操作錯誤。

### AG-VFX-005：視窗縮放與特效座標

操作：

1. 在戰鬥持續時，以 Reduced 模式進行瀏覽器視窗縮放或切換全螢幕。
2. 連續觸發至少 10 次命中或技能特效。
3. 切換到爬塔頁確認 Full 模式，再縮放一次。

預期：

- 特效仍對準敵人與戰場，不會固定偏移到舊位置。
- 縮放後不出現重疊戰場、重複敵人卡片或錯誤的敵人血條。
- Console 無錯誤。

### AG-VFX-006：背景切換與過期特效清理

操作：

1. 在特效播放中切換到另一個瀏覽器分頁，停留至少 5 秒後返回。
2. 立即進行一次強化或洗煉。
3. 再切換頁籤 3 次。

預期：

- 返回後不會一次補播大量過期特效。
- 不殘留過期命中 class、畫面震動或飄字。
- 返回後的裝備操作仍可用，戰鬥狀態與數值保持正確。

### AG-VFX-007：長時間穩定性

操作：

1. 在裝備頁讓戰鬥持續 5 分鐘。
2. 每 30 秒執行一次裝備詳情、洗煉或強化操作。
3. Performance 面板記錄開始與結束時的 DOM 節點數、Memory（若瀏覽器提供）及 Long Task。

預期：

- VFX DOM 節點數不持續無限上升。
- UI 操作延遲不隨時間明顯惡化。
- 沒有逐步增加的 Console 錯誤、Timer 堆積或頁面失去回應。

### AG-VFX-008：戰鬥結果回歸

操作：

1. 記錄同一場戰鬥在 Reduced 模式下的敵人血量、玩家血量、技能冷卻與掉落結果。
2. 切換至爬塔頁讓 Full 模式播放相同類型戰鬥，或使用相同測試存檔重現。
3. 比對戰鬥結果，不比較粒子數或動畫時序。

預期：

- Reduced 與 Full 只改變視覺呈現，不改變傷害、治療、冷卻、資源、掉落與存檔結果。
- Worker 回應與 UI 顯示最終狀態一致。

## 驗收標準

- 所有案例均無 Console error。
- AG-VFX-002 至 AG-VFX-004 的操作沒有遺失、重複或永久鎖定。
- AG-VFX-005 至 AG-VFX-007 沒有座標漂移、節點無限增長或長時間卡頓。
- AG-VFX-008 證明視覺降載沒有改變權威戰鬥結果。
- 若設備效能不足，請記錄實際硬體與可觀察的輸入延遲，不以單一 FPS 數字取代功能驗證。
