# ⚔️ TASK-238：全 18 招「超神進化」技能 DPS 基準測試與前後對比報告

本報告記錄於 **100 級冰原地圖（Icefield）**、**全身 100 級傳奇裝備（強化 +40）** 環境下，所有 6 大技能群組在 **「未點超神進化（1~7 階滿級）」** 與 **「超神進化（第 8 階滿級）」** 18 個分支於三種戰鬥場景下的輸出 DPS、通關耗時與成長倍率對比。

## 1. 測試環境與設定規範

* **角色配置**：
  * 全身 13 格（武器、副手、頭盔、護肩、胸甲、腰帶、手套、護腕、護腿、鞋子、戒指×2、項鍊）均為 **100 級傳奇裝備（Legendary）**。
  * 強化等級：**+40**（詞條屬性乘數 $1 + 40 \times 0.05 = 3.0\times$）。
  * 技能等級：前置 1~7 階全 Lv.10（滿級）；超神進化分支 Lv.10（滿級）。
* **裝備專屬詞條匹配規則**：
  * **突刺**：
    * 幻影八方陣：`evasion`（閃避率）+ `aoeDmg`（範圍傷）+ `atkPct` + `critDmg` + `cdr`。
    * 暗影絕殺者：`aspd`（攻擊速度）+ `pPen`（物穿）+ `atkPct` + `critDmg` + `cdr`。
    * 一擊必殺：`atkPct`（攻擊%）+ `critDmg`（暴擊傷害）+ `pPen` + `cdr` + `hit`。
  * **迴旋斬**：
    * 虛空碎裂斬：`aoeDmg` + `critDmg` + `atkPct` + `atkFlat` + `cdr`。
    * 逐風者：`elemDmgWind`（風傷%）+ `dmgVsWind`（對風傷%）+ `atkPct` + `critDmg` + `cdr`。
    * 天霸風神斬：`aoeDmg` + `atkPct` + `critDmg` + `cdr` + `pPen`。
  * **飛刀**：
    * 暴雨梨花 / 死亡收割者 / 無限追魂刃：`critRate`（100% 暴擊縮 CD）+ `aoeDmg` / `atkPct` + `critDmg` + `cdr`。
  * **疾風斬**：
    * 霹靂一閃：`aspd`（快速累積連擊）+ `critRate` + `atkPct` + `critDmg` + `cdr`。
    * 雷神斬：`elemDmgLightning`（閃電傷%）+ `dmgVsLightning` + `atkPct` + `critDmg` + `cdr`。
    * 千鳥：`aoeDmg` + `atkPct` + `critDmg` + `cdr` + `pPen`。
  * **血刃斬**：
    * 殺神領域：`atkPct` + `critDmg` + `atkFlat` + `cdr` + `pPen`。
    * 萬毒血霧：`elemDmgPoison`（毒傷%）+ `dmgVsPoison` + `atkPct` + `cdr` + `critDmg`。
    * 崩解：`elemDmgPoison` + `atkPct` + `dmgVsPoison` + `critDmg` + `cdr`。
  * **雙刀亂舞**：
    * 毀滅之舞：`hpPct`（生命支持耗血）+ `atkPct` + `critDmg` + `cdr` + `pPen`。
    * 火之神樂：`elemDmgFire`（火傷%）+ `dmgVsFire` + `atkPct` + `critDmg` + `cdr`。
    * 修羅亂舞：雙持雙手巨劍（兩把 Greatsword 享雙手詞條 +40% 加成）+ `atkPct` + `critDmg` + `cdr` + `pPen`。
* **測試敵人（100 級冰原地圖 Icefield）**：
  * **場景 1（小怪群）**：20 隻/波，每 2 秒 1 波，連出 10 波（共 200 隻，單隻 HP ~1.30M / DEF 6,496）。
  * **場景 2（菁英群）**：5 隻/波，每 2 秒 1 波，連出 5 波（共 25 隻，單隻 HP ~5.19M / DEF 6,496）。
  * **場景 3（單體 BOSS）**：1 隻 BOSS（HP ~19.45M / DEF 12,992）。

## 3. 進化前後核心關鍵分析

1. **爆發成長幅度最高王者**：
   * **飛刀 - 死亡收割者**：群怪場景從 280M 暴增至 **8.89B（成長 31.72 倍）**，解決了基礎飛刀打不動 200 隻密集小怪的痛點。
   * **疾風斬 - 雷神斬 / 霹靂一閃 / 千鳥**：群怪與菁英場景從 2.17B 暴增至 **28B ~ 38B（成長 13 ~ 18 倍）**，超神進化後產生了質的飛躍。
   * **突刺 - 一擊必殺**：單體 BOSS 輸出從 529M 暴增至 **5.31B（成長 10.02 倍）**。

2. **機制質變型技能**：
   * **迴旋斬 - 天霸風神斬**：從主動技能轉為**被動自動釋放（0 GCD 佔用）**，群怪 DPS 提升 2.06 倍，使玩家在自動施法時可以騰出主動欄位給其他技能。
   * **雙刀亂舞 - 修羅亂舞**：解鎖副手裝備**第二把雙手巨劍（Greatsword）**，全身雙手武器詞條享受 +40% 強化，整體輸出穩定翻倍（小怪 2.17x，BOSS 1.68x）。

3. **功能 / 生存換取型分支**：
   * **突刺（幻影八方陣 / 暗影絕殺者）** 與 **雙刀（火之神樂）**：數值上未走純直傷路線，而是換取了 **30% 絕對閃避（幻影）**、**300% 易傷輔助（絕殺者）** 或元素附魔，適合高壓高生存需求的攻堅場合。
