# Skills2 同列特效配置

技能說明、本體特效及額外觸發特效保留在同一張 Skills2、同一列。不再使用「特殊效果」的「附加效果／技能本體」標記。

## 如何填寫

本體保留施放特效、攻擊特效、飛行子彈、受擊特效、地板特效、持續場域特效。非空欄覆寫同角色，留白沿前階繼承，超神選項不跨互斥選項繼承。

新增觸發特效、觸發子彈、觸發命中特效、觸發地板特效、觸發持續場域特效，直接填 Preset 名稱。觸發欄只供本列已接線事件；留白不播放，不繼承本體、其他階或已選超神的觸發角色。不能填「附加效果」等用途標籤。

「特效作用說明」同列顯示觸發時機、位置、跟隨行為、縮放依據與可填角色，為工具產生的唯讀說明。沒有獨立觸發欄接線的列會明示，亂填會拒絕匯入。填入特效不會新增技能觸發條件。

## 實作與遷移

tools/skills2-vfx.cjs 定義已接線角色及說明；config_tables.cjs 驗證並生成每列 triggerVfx。空物件也會保留，代表該事件已接線但不播放。執行期明確指定來源列時讀 triggerVfx；普通本體只讀 vfx。預載及編輯器引用掃描都包含觸發欄。

tools/migrate-skills2-vfx.cjs 只產生遷移 JSON，不直接寫正式 Excel。遷移保留非特效欄，搬移現有引用，遇到未盤點用途／不支援角色即拒絕。正式 Excel 經原生 API 更新，正常重開、逐格及圖形數量驗證，再同步 CSV 和生成資料。不能用舊 JS 重建並覆蓋使用者的最新 Excel。

本次沒有更改傷害、間隔、目標選取或飛行佇列規則，也沒有新增素材或額外每幀運算。

殺神領域、萬毒血霧、火神降臨、超重岩之術、超重力場、水牢天瀑、海淵葬界的「領域本身」是玩家身上的狀態：
在超神列的「我方狀態」填代表它的狀態，畫面填在 Status 表該狀態的「持續特效」，依領域實際半徑縮放並逐幀跟著玩家。
這些列不再用地板／觸發地板欄畫領域範圍；萬毒血霧每拍的命中特效仍在本表的觸發欄。
