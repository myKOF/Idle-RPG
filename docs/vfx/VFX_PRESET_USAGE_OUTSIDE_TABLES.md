# 不在配置表、但遊戲中有用到的 Preset

VFX Editor 的 Preset 下拉會在每個 id 後面標出「它被用在哪裡」，這樣挑 preset 時
一眼就看得出哪些已經上場、哪些還是孤兒。

用途來源有兩個：

1. **配置表**（自動掃描，不必維護）
   `config/CSV/Skills.csv`、`Skills2.csv`、`Status.csv` 的特效欄位。
   只要任一欄填了某個 preset id，就算那一列的技能／狀態有在用它。
2. **本檔**（人工維護）
   普攻、天罰、敵方出手這類**不屬於任何一列技能**的固定對應。它們沒有表格
   欄位可填，寫死在 `js/data.js` 的 `VFX_COMBAT_DEFAULTS`。

**兩邊都有的時候兩邊一起顯示**：表上的技能排前面，本檔的用途接在後面。
例如 `proj-ice-shard` 會標成「水流彈·寒霜擴散、冰霜新星·極致之冰、敵方遠程·冰」。

## 為什麼要人工維護一份清單

因為「程式碼裡出現這個字串」不等於「遊戲裡真的用到」，反過來也不成立：
Preset id 也可能出現在註解、測試、Runtime 的特殊處理裡。要判斷一個 preset 是不是孤兒，
需要的是**人**確認過的語意，不是 grep 的結果。

但人工清單會過期，所以有 `tests/vfx-preset-usage.test.cjs` 夾住：

- 本檔列的每一個 id 都必須真的存在於 `vfx/presets/`（USAGE-1）
- 本檔列的每一個 id 都必須真的還在 `js/` 裡被引用（刪掉功能卻忘了刪這一列 → 轉紅，USAGE-2）
- `js/` 裡被引用、而配置表沒有的 preset，都必須列在本檔的其中一段
  （新增寫死對應卻忘了登記 → 轉紅，USAGE-3）
- `VFX_COMBAT_DEFAULTS` 裡的每一份都必須列在「清單」，**表上也有人用的一樣要列**（USAGE-3B）
- 「程式有引用、但不算用途」的每一列都要站得住：還在 `js/` 裡、沒有別的用途、寫了理由（USAGE-3C）

也就是說：**這份清單不會靜靜地過期**，它只會在你改動的當下轉紅一次。

### 更新紀錄

- **2026-09-09**：普攻原本掛 `slash-phys-big`（斬擊本體）＋ `proj-swordwave`（飛出的劍氣）＋
  `hit-phys`，後來整組換成單一的命中爆點，爆點本身又從 `hit-basic-burst` 換成
  `hit-basic-irregular`（兩次都是 USAGE-2／3 抓到的）。`slash-phys-big` 與 `proj-swordwave`
  因此變成孤兒——preset 檔還在，但遊戲裡已經沒有人用。
- **2026-09-14**：使用者回報敵方的冰片子彈在遊戲裡到處都是，下拉上卻沒標。原因是舊規則
  「表上有人用就不必登記，而且表上有的就不顯示本檔」——`proj-ice-shard` 被水流彈與冰霜新星的
  階段用到，冰屬性敵人那一邊就整個隱形。同樣被吃掉的還有毒／風的敵方投射物、七種屬性的
  敵方爆點、小隕石的爆點與兩種連鎖電擊。規則改成兩邊一起顯示，這些全部補登記，由 USAGE-3B 守住。
  同時把 `bolt-sky-lightning` 的「天罰／連鎖閃電」更正為「天罰／雷霆過載」：
  `chainLightning` 那一組是潛力技能雷霆過載在用，不是技能表上的【連鎖閃電】。

## 程式有引用、但不算用途

`js/` 裡找得到這些 id，但確認過遊戲實際上不會播放它們。列在這裡是讓 USAGE-3 知道
「這不是忘了登記」，同時把理由留下來——下拉上它們仍然顯示成孤兒，那是正確的。
格式與上一段相同，第二欄改寫「為什麼不算用途」、第三欄寫程式位置。

| preset id | 為什麼不算用途 | 程式位置 |
| --- | --- | --- |
| `ground-firewall` | 火龍捲第 7 階在 2026-09-12 由無限火牆改成無限火龍，技能表已經沒有任何一列填它 | `js/vfx-runtime.js` 還留著火牆三柱的播放處理 |

哪天技能又用回它（表上填了），USAGE-3C 會轉紅提醒把這一列刪掉。

## 格式規定（測試會檢查）

- 文件裡有兩張表，靠所在的 `## 標題` 分辨：`## 清單` 是用途，`## 程式有引用、但不算用途` 是豁免。
  標題改名的話那一段就讀不到（USAGE-3／3B 會轉紅）。
- 表格只有三欄，順序固定：id、顯示標籤（豁免段是理由）、用在哪裡（豁免段是程式位置）。
- id 一律用反引號包起來，不加副檔名。
- 顯示標籤不得含有半形括號 `()`，也不得含逗號——它會被塞進 `「<id>（<標籤>）」` 這個字串裡。
- 同一個 id 有不同用途時各寫一列，兩列的標籤不要一樣。

## 新增一筆的時機

在 `js/` 裡新增一個「寫死的 preset 對應」的時候——**不管表上是不是也有人在用那份 preset**。
如果那個對應**應該**填在表上，正確的做法是去填表，不是登記到這裡；
本檔是給「結構上沒有欄位可填」的情況用的，不是給偷懶用的。
