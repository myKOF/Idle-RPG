## 噴火粒子與尺度

`fire.json` 是此預覽粒子的唯一參數來源，`fire.js` 是本次自製的 instanced billboard 粒子實作。包含帶噪聲的火團、高亮近端火芯、火星、煙霧及嘴部暖光，無外部圖像依賴。每顆粒子使用發射時刻的嘴部位置與方向，離開嘴後不跟隨骨頭滑動。

- 成品 GLB 的 1 世界單位＝1 米；來源模型統一放大 4 倍，並寫入 asset root，不在預覽端另行猜測尺寸。
- `MouthSocket` 骨掛點的本地 +Y 為發射方向，不能誤用成品 glTF 的世界 +Z 直接代替掛點旋轉。
- `Attack3` 的 0.88～2.16 秒發射；粒子以每秒 40 米飛行，最長壽命 0.75 秒，名義射程 30 米。擾流及火團半徑形成可見邊緣，不代表新增遊戲傷害範圍。
- GIF 同時顯示 30 米全景標尺與飛龍動作近景；預覽本身無音訊。
- 標準 GLB 不攜帶此類即時粒子系統。`boss9.glb` 包含角色、五個動作和嘴部掛點；火焰由伴隨的 `fire.js`／`fire.json` 同步呈現。這不是已接入遊戲的 VFX Preset。後續若接入，仍須依專案 VFX 來源與戰鬥事件規則處理，不能只換模型便宣稱火焰已上線。

## 保存與重建

素材庫位置由 `tools/vfx/vfx-library-root.cjs` 解析。套件相對路徑：`codex-authored/boss9-dragon-20261119/`。

- `source/BOSS9.glb`：原檔。
- `exports/boss9.blend`：可編輯骨架、蒙皮、五個 Actions 與打包原圖。
- `exports/boss9.glb`：預覽成品。
- `exports/build.json`／`validation.json`：製作及原生蒙皮驗證。
- `tools/`：本目錄製作、粒子、預覽及驗證工具副本。
- `previews/`：五個 GIF；`qa/capture.json`：成品載入及粒子驗證。
- `manifest.json`：SHA-256 清單；文字檔以 LF 正規化比對。

```powershell
blender -b --python-exit-code 1 -P tools/boss9/build.py -- <原檔.glb> <輸出目錄>
blender -b --python-exit-code 1 -P tools/boss9/verify.py -- <輸出目錄/boss9.blend> <驗證.json>
node tools/boss9/capture.cjs <逐幀目錄>
python tools/boss9/encode.py <逐幀目錄> <GIF目錄>
node tools/boss9/export.cjs
```

`capture.cjs --serve` 開啟唯一本機預覽服務；前台審閱結束後以 Ctrl+C 關閉。擷取使用專案 headless browser 包裝器，正常與異常結束皆關閉專用瀏覽器。GIF 編碼需要 Pillow；Blender 不需要額外安裝套件。
