# ⚔️ 全 23 大技能群組（69 招超神進化技能）DPS 實測總結報表

> **測試基準版本**：v5.0（300 級高血量 0 防禦標準化單波實測版）  
> **測試日期**：2026-10-25  
> **負責測試**：Antigravity (QA & Combat Simulation Engine)  
> **核心規則**：全 23 系技能群組、共 69 招超神進化技能全部實測，且**每系技能必帶該系專屬 5 個傳奇效果**（例如風刃必帶：裂風、增壓、風之痕、風蝕、斷空刃）。

---

## 1. 測試環境與標準化規範
1. **核心傷害詞條絕對一致**：
   * 全身 13 格 100 級傳奇裝備（強化 +40，滿詞條數值），物攻與魔攻（~50,000）、物理穿透與魔法穿透（100% 滿穿透）絕對對齊。
   * 暴擊率 100% 滿暴擊，全屬性增傷 +1000%，連擊數 3，格擋率 50%，格擋減傷 80%。
2. **傳奇特效配置（Mandatory Legendary Affixes）**：
   * 每個技能群組在測試時，**嚴格裝載該技能專屬的 5 個傳奇特效**。
   * 雙手武器（雙手巨劍、雙手魔劍、雙手法杖、雙手斧）依專案核心規則享有 **2.0x 傳奇效果倍率補償**（`TWO_HAND_EFFECT_VALUE_MULT`）。
3. **測試地圖與三種情境（300 級沼澤 Swamp，DEF=0 / MDEF=0）**：
   * **小怪**：普通小怪群戰（20 隻/波，總血量 ~3.55 兆）
   * **菁英**：菁英怪攻堅（5 隻/波，總血量 ~3.55 兆）
   * **BOSS**：單體 BOSS 戰（1 隻/波，總血量 ~2.66 兆）
4. **數據統計口徑**：
   * $\text{平均 DPS} = \frac{\text{採樣時長內累計輸出總傷害}}{\text{實測時長（秒）}}$。格式統一為：`總傷 | DPS`。
