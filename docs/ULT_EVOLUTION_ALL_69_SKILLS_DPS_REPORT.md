## 1. 測試環境與標準化規範

### 1.1 核心傷害變因嚴格控制規範
1. **核心傷害詞條絕對一致**：
   * 全身 13 格 100 級傳奇裝備（強化 +40，滿詞條數值），物攻與魔攻、物理穿透與魔法穿透絕對對齊：
     * `atkPct` / `matkPct`：攻擊百分比（物魔雙加成滿 roll）
     * `atkFlat` / `matkFlat`：基礎攻擊值（物魔雙基準一致，~50,000）
     * `critDmg`：爆擊傷害（全身詞條滿 roll）
     * `critRate`：爆擊率（100% 滿爆擊，完全剔除未暴擊變因）
     * `pPen` / `mPen`：物理穿透 / 魔法穿透（100% 滿穿透）
2. **公平基準全域加成**：
   * 格擋率（`blockRate`）：**50%**
   * 格擋減傷（`blockDmgRed`）：**80%**
   * 連擊數（`comboHits`）：**3**
   * 全屬性增傷害（`totalDmgPct`）：**+1000%**
   * 元素傷害增幅（`elemDmgPct` / `elemDmgUp`）：**+1000%**
3. **傳奇特效配置（Mandatory Legendary Affixes）**：
   * 每個技能群組在測試時，**嚴格裝載該技能專屬的 5 個傳奇特效**。
   * 雙手武器（雙手巨劍、雙手魔劍、雙手法杖、雙手斧）依專案核心規則享有 **2.0x 傳奇效果倍率補償**（`TWO_HAND_EFFECT_VALUE_MULT`）。
   * 雙刀亂舞【修羅亂舞】適配雙持雙手巨劍（主手副手皆巨劍）。
   * 盾牌類技能（反擊、大地守護、暴風屏障）適配主手單手武器 + 副手盾牌。
4. **測試地圖與三種情境（300 級沼澤 Swamp，DEF=0 / MDEF=0）**：
   * **情境 1（普通小怪群戰）**：20 隻/波（小怪總 HP ~3.55 兆）。測試群體割草、穿透、擴散與 AOE 機制。
   * **情境 2（菁英怪攻堅）**：5 隻/波（菁英總 HP ~3.55 兆）。測試高血量分散目標攻堅與彈射機制。
   * **情境 3（單體 BOSS 戰）**：1 隻/波（BOSS 總 HP ~2.66 兆）。測試純單體持續爆發與斬殺機制。
5. **採樣與統計公式**：
   * $\text{平均 DPS} = \frac{\text{採樣時長內累計輸出總傷害}}{\text{實測時長（秒）}}$。
   * 怪物定期攻擊玩家，以完整激發受擊反應、反擊、格擋、護盾消耗及流血/燃燒觸發機制。

   * **群體割草首選**：落雷術（雷電矩陣 10.18B）、風刃（嵐之山 5.03B）、突刺（一擊必殺 4.30B）、風刃（天穹崩裂 4.12B）。
