# Antigravity 測試用例：VFX 編輯器的多視窗預覽

## Feature

2026-09-17 使用者需求（VFX 編輯器多視窗同時預覽及調整）：

1. 預覽區上方的「＋ 新增視窗」把預覽區切出新的一格：兩格左右並排（原本的在左）、
   三格時第三格橫跨下排、四格十字切開；最多四格。
2. 點哪一格焦點就到哪一格：Layers、Inspector、工具列顯示那一格的特效，載入特效、新增圖層都作用在那一格。
3. 視窗之間可以互相複製貼上圖層：A 視窗選 a1 按 Ctrl+C，點 B 視窗按 Ctrl+V。
4. Ctrl+點擊可以多選視窗；工具列的「暫停／播放」「⟲ Restart」「預覽循環」一起套用到多選的全部視窗。

連帶的行為改變（使用者要先知道，QA 也要驗）：

- 切換特效（搜尋下拉、瀏覽特效、另存新檔之後的重開）**不再整頁重新整理**，改成就地換掉那一格的內容。
- 網址記住每一格開的特效：`?preset=a&preset=b&focus=2`，重新整理後還原。
- 「⟲ Restart」修正成真的從頭播（2026-09-02 之後它一直只是原地重建、接著目前的時間播）。

對應 commit：`556fac9f`（pane-model 純邏輯）與之後的編輯器接線、跨視窗貼上兩個 commit。

## Test Goal

這次 QA 要證明三件事，其餘是附帶：

- **改 A 格不會改到 B 格。** 每一格有自己的歷史、選取、未存檔狀態與存檔目標。
  這種錯不會報錯，只會在存檔之後才發現另一份特效被改了。
- **存檔、另存新檔的結果寫回按下去的那一格。** 存檔回應回來之前就點去別的格子，
  「已存檔」「未存檔」「存檔失敗」都不能跑到眼前那一格上。
- **跨視窗貼上後畫面位置不變。** 貼過去的圖層若原本掛在沒一起複製的父物件底下，
  會改成根層級並換算數值，在新的那一格裡要出現在同樣的位置、角度、大小。

其餘是迴歸：只有一格時編輯器要與以前完全相同。

## Preconditions

### 分支

在 `ai/claude`，Antigravity 的 worktree 沒有。**先合併再測**，不要直接開 claude 那份工作副本
（`VFX_AGENT_WORKFLOW §3.3`）：

```bash
git -C D:/MyGame/Idle-RPG/antigravity merge --no-ff ai/claude
```

### 啟動編輯器

在 **`D:\MyGame\Idle-RPG\antigravity`** 執行 `啟動VFX編輯器.bat`，並確認連到的是自己那份：

```bash
curl -s http://127.0.0.1:<實際開啟的埠>/__whoami
```

必須回 `idle-rpg-vfx-editor D:\MyGame\Idle-RPG\antigravity`，否則這次結果全部作廢。

### 其他

- 開著 DevTools Console，全程不得出現任何錯誤。
- 測試用 preset：`lightning-orb-field`（雷球，含粒子層）、`hit-fire`、`demo-basic`。
- **會寫檔的案例是 AG-VFXMP-007、008。** 做完用 `git -C D:/MyGame/Idle-RPG/antigravity status`
  確認改到了哪些檔，再用 `git checkout -- <檔案>` 還原；另存新檔產生的新檔案要刪掉
  （`vfx/presets/<新名字>.json` 與 `vfx/layouts/<新名字>.json`）。回報時附上還原前的 `git status`。

## Test Steps / Expected Result

### AG-VFXMP-001：只有一格時與以前相同（迴歸，最先做）

操作：

1. 開 `.../?preset=lightning-orb-field`。
2. 拖曳圖層、改 Inspector 數值、Ctrl+Z／Ctrl+Y、滾輪縮放、右鍵拖曳平移、暫停再播放。
3. 用搜尋下拉切到 `hit-fire`。

預期：

- 預覽區沒有任何外框或左上角標籤，畫面與合併前一模一樣。
- 步驟 3：**頁面不重新整理**（搜尋框的篩選字、Console 的訊息都還在），預覽、Layers、Inspector
  換成 `hit-fire`，縮放回到 100%，復原按鈕變成停用；網址變成 `?preset=hit-fire`。
- 有未存檔修改時切換，要先跳出「目前的修改尚未存檔…」的確認；按取消就留在原本那一份。

### AG-VFXMP-002：新增視窗與版面（最重要）

操作：

1. 開 `.../?preset=lightning-orb-field`，按背景色列上的「＋ 新增視窗」。
2. 再按兩次。
3. 再按一次。

預期：

- 步驟 1：左右兩格，左邊是雷球、右邊是空白格；右邊那一格有亮藍色外框（焦點），
  左上角標籤寫「2 new-effect」。Layers 是空的，右側「驗證」寫著還沒有任何圖層的說明。
- 步驟 2：三格時第三格橫跨整個下排；四格時十字切開，四格一樣大。
- 步驟 3：按鈕是停用的（最多四格），沒有第五格。
- 每一格的特效都在自己格子的正中央，格線對齊；**任何一格都不能被裁掉一塊或畫到別格裡**。
- 改變瀏覽器視窗大小、拉窄側欄，四格都要跟著調整。

### AG-VFXMP-003：焦點切換

操作：

1. 兩格：左 `lightning-orb-field`、右 `hit-fire`（右邊那格選中後用搜尋下拉載入）。
2. 點左格的空白處，再點右格的空白處，反覆幾次。
3. 在左格選一個圖層、拖曳它；再點右格選一個圖層。

預期：

- 點哪一格，亮藍外框就在哪一格；Layers、Inspector、搜尋框顯示的特效名稱、「● 未存檔」、
  復原／重做按鈕跟著換成那一格的。
- 點空白處不會取消原本的圖層選取；**只有焦點那一格畫得出圖層的框與把手**。
- 點一下另一格上的圖層：焦點換過去，同時選到那個圖層（不必點兩下）。
- 在某一格打開搜尋下拉選一份**已經開在另一格**的特效：焦點直接跳到那一格，
  狀態列寫「已經開在視窗 N，已切換過來」，不會開成兩份。

### AG-VFXMP-004：每一格的修改與復原互不影響（最重要）

操作：

1. 兩格：左 `lightning-orb-field`、右 `hit-fire`。
2. 在右格停用一個圖層（Layers 的勾選框）。
3. 點左格，按 Ctrl+Z。
4. 點右格，按 Ctrl+Z。

預期：

- 步驟 2：右格標籤出現「●」，工具列「● 未存檔」亮起；左格沒有。
- 步驟 3：左格沒有東西可復原（按鈕停用），右格的停用**沒有**被復原。
- 步驟 4：右格的停用被復原，「●」消失。

### AG-VFXMP-005：多選視窗與播放控制

操作：

1. 三格都開著特效。點第一格，Ctrl+點擊第二格。
2. 按「⏸ 暫停」，再按「▶ 播放」。
3. 按「⟲ Restart」。
4. 取消勾選「預覽循環」。
5. Ctrl+點擊第二格（移出多選），勾回「預覽循環」，再 Ctrl+點擊第二格加回來。
6. 一般點擊第一格（它在多選裡）；再一般點擊第三格（不在多選裡）。

預期：

- 步驟 1：第二格亮藍外框（焦點），第一格暗藍外框（多選但不是焦點），第三格沒有外框。
- 步驟 2：第一、二格一起停、一起播；第三格照常播放。暫停中的格子標籤有「⏸」。
- 步驟 3：第一、二格**同時從頭**播（兩份特效的起點對齊），第三格不受影響。
- 步驟 4：第一、二格播完不再重播。
- 步驟 5：加回來之後「預覽循環」勾選框變成「－」（兩格設定不一致）；再點一下兩格一起變成同一個值。
- 步驟 6：點第一格只換焦點、多選不變；點第三格變成只選第三格。

### AG-VFXMP-006：關閉視窗

操作：

1. 四格，在第四格新增一個圖層（變成未存檔）。
2. 按第四格標籤上的 ✕，在確認框按取消；再按一次 ✕，按確定。
3. 按第三格（空白、沒動過）的 ✕。
4. 關到剩一格。

預期：

- 步驟 2：未存檔要先問，訊息寫出是哪一格、哪一份；取消就留著。確定後剩三格、版面重排，
  焦點移到前一格。
- 步驟 3：沒動過的空白格直接關掉，不問。
- 步驟 4：只剩一格時標籤與 ✕ 消失，畫面回到與以前相同。
- 反覆新增、關閉十次以上，Console 不得出現「Too many active WebGL contexts」之類的警告。

### AG-VFXMP-007：存檔寫回按下去的那一格（會寫檔）

操作：

1. 兩格：左 `lightning-orb-field`、右 `hit-fire`。
2. 在右格改一個數值，按「儲存到 repo」後**立刻**點左格。
3. 等一兩秒，再點回右格。
4. 在右格改一個數值，按 Ctrl+S。

預期：

- 步驟 2～3：左格的工具列不會出現「已存檔」；點回右格才看到「已存檔 · N bytes」，「●」消失。
- `git status` 只有 `vfx/presets/hit-fire.json`（與它的 layout）被改，`lightning-orb-field` 沒有。
- 步驟 4：Ctrl+S 存的是右格那一份。

### AG-VFXMP-008：另存新檔與空白格的第一次存檔（會寫檔）

操作：

1. 兩格：左 `demo-basic`、右空白格。
2. 在右格按「＋ 新增」加一個 sprite 圖層並選好素材，按「儲存到 repo」。
3. 在存檔視窗輸入新名字（例如 `zz-multi-pane-qa`）。
4. 在左格按「另存新檔」，輸入另一個新名字。

預期：

- 步驟 2：空白格的名字是暫時的，按「儲存到 repo」會跳出**另存新檔的視窗**問名字（不會直接寫成 `new-effect.json`）。
- 步驟 3：右格就地換成新名字（**頁面不重新整理**，左格還在），狀態列寫「已另存為…」，復原紀錄清空，
  Layers 的根群組名稱是新名字。
- 步驟 4：左格換成新名字、繼續播放；右格不受影響。網址列出兩個新名字。
- 做完刪掉產生的新檔案。

### AG-VFXMP-009：跨視窗複製貼上（最重要）

操作：

1. 兩格：左 `lightning-orb-field`、右 `hit-fire`。
2. 左格選一個圖層，Ctrl+C。Layers 下方應顯示「剪貼簿：1 項（lightning-orb-field）」。
3. 點右格，選一個圖層，Ctrl+V。
4. 在右格按 Ctrl+Z。
5. 左格選根群組列，Ctrl+C；點右格選根群組列，Ctrl+V。
6. 在左格把一個圖層掛到另一個圖層底下（Inspector 的「父物件」），並把父物件轉個角度、放大；
   只選子物件複製，貼到右格。

預期：

- 步驟 3：貼上的圖層**沿用原本的名字**（右格沒有同名時不加 `-copy`），出現在右格根群組裡、
  排在選中的圖層後面；位置與左格裡看到的相同。狀態列寫「已從 lightning-orb-field 貼上 1 層」。
- 步驟 4：只復原右格的貼上，左格不受影響。
- 步驟 5：全部圖層貼進右格的根群組，**不會多出第二個群組**；撞名的圖層加序號。
- 步驟 6：貼過去的圖層沒有父物件（右格裡沒有那個父物件），但**畫面上的位置、角度、大小與左格裡一樣**；
  狀態列說明「父物件沒有一起複製，貼上後改成根層級…」。
- 在同一格裡複製貼上仍然是原本的規則（名字帶 `-copy`）。

### AG-VFXMP-010：重新整理後還原

操作：

1. 三格：`lightning-orb-field`、空白格、`hit-fire`，焦點在 `hit-fire`。
2. 按 F5（沒有未存檔修改）。
3. 有未存檔修改時按 F5。

預期：

- 步驟 2：網址是 `?preset=lightning-orb-field&preset=hit-fire&focus=2`；重新整理後兩格
  （空白格不會還原），焦點在 `hit-fire`。
- 步驟 3：瀏覽器跳出離開頁面的確認。

## Edge Cases

1. **載入途中切換**：在一格用搜尋下拉連續快速選三份不同的特效——最後顯示的必須是最後選的那一份，
   不得先出現最後一份、又被比較慢回來的前一份蓋掉。
2. **載入途中關閉**：選一份大的特效後立刻按那一格的 ✕——不得出現錯誤、不得在別格出現那份特效。
3. **輸入框打到一半就點別格**：在 Inspector 的數值欄位打字（不按 Enter），直接點另一格——
   那個修改要留在原本那一格，而且在原本那一格按 Ctrl+Z 復原得掉。
4. **四格都在播放含粒子的特效**時，操作是否仍然順暢；滾輪縮放只影響滑鼠底下那一格。
5. **載入 Preset（本機檔案）**選到一份已經開在另一格的特效——要被擋下並說明原因。
6. **瀏覽特效**裡按「複製成新特效」，而那一份開在另一格——焦點要跳到那一格並跳出另存新檔。
7. **貼上到空白格**：空白格貼上之後就是一份可以存檔的特效（存檔時要問名字）。
8. 在一格拖曳圖層時，把滑鼠拖到另一格上方再放開——只改到開始拖曳的那一格。

## Visual / UX checks

1. 焦點（亮藍）與多選（暗藍）的外框分得出來嗎？在淺色背景上看得清楚嗎？
2. 左上角的標籤會不會擋到特效或 gizmo 的把手？四格時名字太長會不會被截得看不出是哪一份？
3. 「＋ 新增視窗」的位置找得到嗎？四格時它變成停用，看得出為什麼嗎？
4. Ctrl+點擊多選之後，「暫停／Restart／預覽循環」會作用在多格，這件事看得出來嗎
   （按鈕的滑鼠提示有寫「選取的 N 個視窗一起」）？
5. 切換特效不再重新整理頁面，使用上有沒有哪裡覺得「沒換乾淨」（上一份的東西殘留在畫面上）？
6. 跨視窗貼上之後的狀態列說明，第一次看的人看得懂嗎？

## 回報格式

每個案例回報：**通過 / 失敗 / 部分通過**，失敗時附上：

- 實際觀察到的現象（不是推測的原因）
- 重現步驟（哪幾格、各開哪一份、操作順序）
- Console 的錯誤原文
- 截圖（版面與位置類的問題一定要附圖）
- 瀏覽器版本、作業系統、螢幕解析度

另外一律回報：

- 測試前後的 `git -C D:/MyGame/Idle-RPG/antigravity status`，以及還原與刪除了哪些檔案
- `/__whoami` 的回應（證明測的是自己那份副本）
