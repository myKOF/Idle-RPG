# 薩爾維恩世界地圖

世界名為「薩爾維恩」，英文設定名 Salvien，意為「神聖與黑暗力量的交界」。地圖圖稿只顯示中文名。

世界地圖預設開放。戰鬥區保留目前場景、關卡、前後／最高、自動推進、全螢幕和迷你視窗，其他場景改由「世界地圖」選取。

- 移至場景文字附近或以鍵盤聚焦：查看場景名稱、已推進關卡／場景上限、目前所在地或解鎖條件。
- 點擊／觸控或按Enter選取：資訊卡保持開啟，顯示「前進」。只有已解鎖且非目前場景可前進；未解鎖場景仍可查看條件。
- 按前進後沿既有 `stage.switchZone` Worker指令切換，回到該場景原先停留的關卡。地圖等到權威快照確認成功才關閉；失敗可重試。
- 深綠／淺綠分面的卡通指針標示目前人界場景，橫向較最初箭頭參考縮窄約20%，目前顯示再整體縮小20%。指針固定朝下、不旋轉，以2.4秒週期上下浮動6px，下方小光圈同步於透明度0.4～0.95間呼吸。依使用者要求提高可見性，系統減少動態偏好下仍保留此微幅所在地提示。
- 地圖等比放大，收去原圖最外緣白底，沒有額外的上下標題／說明列；關閉按鈕以圓形古銅金屬框融入地圖右上裝飾。場景熱區沒有橢圓框／底色，滑過時只放大提亮名稱。資訊卡固定在該場景名稱與進度下方，桌面與窄螢幕均不向上翻轉或貼齊視窗底部，僅水平限縮以免超出地圖兩側。
- 原名稱烘焙在圖內；常駐同位置的無字地貌小覆片，再以DOM顯示名稱。已解鎖名稱統一為落雷峰風格的淡金色並加1px黑邊，下方以括號顯示最高到達關卡／場景上限，退關及切換場景不降低最高紀錄；未解鎖名稱為灰色並保留黑邊，隱藏括號進度，資訊卡的推進關卡顯示0。資訊卡對已解鎖場景同樣顯示最高推進關卡。hover／focus／選取保留名稱放大，離開仍顯示狀態。七張覆片沿用既有素材，完整地圖PNG不變。底圖不接收滑鼠事件且禁止拖曳，避免瀏覽器圖片AI浮鈕，點擊背景仍取消選取。圓框內叉號為對稱SVG線條，不依賴字型基線。
- Esc、關閉按鈕或點擊遮罩關閉，焦點返回入口；Esc先關地圖，不會同時退出戰鬥全螢幕或開啟菜單。鍵盤Tab限制於地圖視窗。
- 人界上限最高的地圖真正通關後，人界圖左上方海面出現「神界傳送門」。最高上限由`ZONES`中`realm === 'human'`的`maxStage`動態取得，不綁定亡靈山脈；若並列最高，須皆通關。使用既有`battle.zoneProgress[key].cleared`判斷，只到達末關或缺快照時不顯示。傳送門為CSS介面圖形，不改核准圖稿或新增VFX素材。
- 點傳送門開啟神界頁，並保留人界返回按鈕，不立即傳送。神界三圖取消轉生及等級門檻：亡靈山脈400關通關解鎖太古戰場、太古戰場450關通關解鎖混沌界、混沌界500關通關解鎖永恒神域，0轉也能依序前進。各場景由權威`battle.zones.unlocked`及既有前置通關條件控制前進；既有神界進度或轉生數對應的頁籤入口也保留。
- 神界傳送門採自製可編輯的內嵌SVG金屬拱門、刻紋／頂冠寶石；取消石階及實體門座，改用帶淡金受光的象牙白浮雲承托。門內三道香檳金螺旋交疊金白柔光，中心為漸淡神光與細長光芒，沒有深黑洞口或硬邊核心圓環；旋流放緩並保留深淺層次、光紋與星點，門外有暖金呼吸光暈、四道循環氣流及上升光粒，浮雲微幅飄移。旋流在SVG內旋轉再投影為橢圓，門框保持穩定，hover／鍵盤focus僅微幅抬升提亮，保留焦點框；地圖隱藏時動畫不呈現，縮減動態偏好停止所有門體動畫並保留靜態形態。窄視窗入口稍下移以避開原圖頂端裁切。全部為既有介面標記與樣式，沒有新增Timer、戰鬥VFX Preset或獨立美術圖檔；名稱繼續讀取String 2206，入口及前進條件不變。

## 推關規則

內部GM「亡靈山脈400關設為已通關」轉成 `stage_clear 亡靈山脈 400`：補齊前面所有場景通關並提升目標 `cleared`，後續進度、目前所在地與轉生數保留，不補獎勵。真Worker刷新既有快照後顯示入口，存檔沿用原通關欄位。`stage`／`stage_jump`仍代表到達但尚未通關指定關，並重設後續進度，不能當成「已通關」。

自動推進僅在目前場景內運作。打贏最後一關仍更新 `zoneProgress[zone].cleared`，解鎖條件維持真正通關前圖末關；`best`維持場景上限。中途場景留在末關繼續戰鬥，下一章必須由玩家主動前進，無論後續場景是否已解鎖。真正最後的神界場景完成與停止出怪語意保持。

進度、關卡上限及可前進狀態讀取既有 `header.stage` / `battle.zones` 快照，沿用權威 `isZoneUnlocked` 判定，不新增存檔／Protocol欄位或另一份關卡配置。未取得場景快照時禁止前進。圖稿內七個人界名稱使用比例座標熱區，隨圖片寬度縮放；換圖時需要重新校準 `js/ui-world-map.js` 的 `locations`，不得僅替換圖像而不驗證熱區。

## 圖稿保存

來源為本聊天由使用者提供原圖並逐次核准的內建imagegen編修稿，使用者明確指定加入本遊戲。採用最終「左下海獸移除／火山煙修正」版本，不再調色、縮放或重新生成。參考及編修範圍詳素材庫 `codex-authored/world-map/SOURCE.md`，必要母圖與SHA256在相鄰`source.json`。本次使用依據僅針對使用者指定圖稿，不推定其他素材包的授權。

由共用 `tools/vfx/vfx-library-root.cjs` 解析本機素材庫位置。執行：

```text
node tools/world-map/export-source.cjs --apply
node tools/world-map/export-source.cjs --check
```

遊戲載入 `images/world-map/salvien.png` 與 `images/world-map/location-cursor.png`。匯出逐位元保留核准圖稿，`--check`核對母圖紀錄／素材庫／遊戲SHA256。游標使用內建imagegen製作，母圖及完整提示詞保存在素材庫的SOURCE.md；詳來源僅參考使用者箭頭造型並自行生成卡通圖。所在地標記是一般UI CSS動畫，不是技能VFX Preset。
