# 寶石共鳴系統

需求來源：企劃文件〈寶石共鳴系統〉（Google 試算表，含界面示意圖、鑲孔區域示意圖、界面風格示意圖）。
入口：寶石分頁 → 工坊分頁列最右邊的「共鳴」。

## 規則（已實作）

| 項目 | 規則 |
| --- | --- |
| 版面 | 7 區 × 7 孔 = 49 孔。6 個外圍區（魔法傷害、防禦、元素抗性、屬性傷害、回復、物理傷害，從正上方順時針）環繞中央區（任意）。每區孔 0＝中心、孔 1~6＝外圈（從正上方順時針）。 |
| 種類限制 | 外圍區各限定寶石種類；中央區不限種類，只有階級要求。 |
| 中央解鎖 | 外圍六區全部42個鑲孔皆達強化滿級（配置目前10級），中央七孔才開放。未解鎖時置灰、不能鑲入／升級，中央既有寶石及相鄰加成暫停；舊資料與孔等級保留，允許取下寶石。解鎖由外圍孔等級即時計算，不另存旗標。 |
| 最低階級 | 外圍區：朝外的三個外圈孔 4 階、朝內的三個 5 階、中心 6 階（圖 2「防禦」區 4/4/4/5/5/5、中心 6）。中央區：外圈 8 階、中心 10 階。可鑲更高階，不可鑲更低階。 |
| 容量 | 外圈孔 1 顆；外圍區的中心孔 2 顆；中央區的中心孔 6 顆。 |
| 自身能力 | 孔內每顆寶石提供自己的能力（與裝備鑲嵌同一套數值與「寶石鑲嵌效率」放大）。 |
| 孔等級 | 每孔 0~10 級（初始 0）。接收孔已鑲寶石時，每級額外獲得「相鄰孔每顆寶石」能力的 3%，上限 30%；接收孔有多顆寶石不會倍乘。空孔仍可升級，但不產生任何共鳴加成。 |
| 升級花費 | 金幣＋指定階級的寶石，階級與顆數逐級遞增（見配置表）。**孔不必鑲寶石也能升級**：孔裡有寶石就扣同種類；空孔則扣本區允許種類中庫存夠付、存量最多的一種（中央區不限種類）。 |
| 取下 | 寶石退回庫存；孔等級保留。 |

## 設計上的判定（企劃文件沒寫清楚、由實作者決定，請企劃確認）

1. **「相鄰」的定義**：同一區域內，中心孔與六個外圈孔互為相鄰，外圈孔再與左右兩個外圈孔相鄰；**不跨區域**。
2. **各區可鑲的寶石種類**（圖 1 看不到文字清單，依能力歸類）：
   魔法傷害＝藍寶石、穿魔、堇青石、紫水晶、石榴石；
   物理傷害＝紅寶石、穿甲、蛋白石、貓眼石；
   防禦＝鑽石、青金石、黃玉、月光石、翡翠、珍珠、孔雀石、螢石；
   元素抗性＝八種抗性寶石與全屬性抗性；
   屬性傷害＝八種對屬性增傷與八種屬性傷害提升（核寶石）；
   回復＝綠寶石、藍晶石、黑曜石、魔晶石。幸運（太陽石）等其餘種類只能放中央區。
3. **升級花費的數字**（金幣、寶石階級、顆數）文件只說「遞增」，目前是佔位值，請企劃在配置表調整。
4. 孔內寶石在存檔載入時若不符合目前配置表（種類、階級、容量），會**退回庫存**而不是消失。
5. 空孔升級扣哪一種寶石是實作者決定的（見上），不必挑種類。
6. BOSS 戰中禁止鑲嵌／取下（與裝備鑲嵌同規則）；升級不受限。

## 配置表 `Gem_resonance`

- 檔案：`config/Excel/Gem_resonance.xlsx` → `config/CSV/Gem_resonance.csv` → `js/gem_resonance_data.js`（`GEM_RESONANCE_SETTINGS`／`GEM_RESONANCE_REGIONS`／`GEM_RESONANCE_UPGRADES`）。
- 一張表三種列（「類型」欄）：設定／區域／升級。欄位寫法見 `tools/config_tables.cjs` 的 Gem_resonance 區塊註解。
- 改完存檔後雙擊「套用參數.bat」；打錯種類、孔位數、升級列不連續等一律整次中止並指出位置。

## 介面操作

- 每次從其他工具或主分頁切入共鳴，預設選中物理傷害區左上外圈孔（phys區第6孔），左側同步篩選該孔適用寶石；頁內選孔、刷新與重按目前工具保留當前選擇。
- 滑鼠左鍵按下共鳴孔即選中，不必等放開；右鍵不改變選孔，鍵盤 Enter／空白鍵仍可選孔。選中後，左側寶石庫只列出符合該孔種類限制的寶石類型，一種類型一列；分類與「只看持有」仍可使用。左側點擊只切換上方顯示的類型。
- 選中孔所在區域的7孔一起亮起，沿用該區顏色加亮水晶切面與邊緣，提示篩選寶石對應的區域；跨區選孔時亮起區域同步切換，單孔仍以六角框標記。區域亮起包含已滿／已鑲與階級需求不同的孔，實際是否能鑲仍依上方禁用狀態與拖曳合法／拒絕提示判斷。
- 未解鎖的中央七孔持續置灰，不套用整區亮起；可以選孔並從升級按鈕Tooltip查看解鎖條件、點擊已鑲寶石取下，上方十階鑲入及右側升級均停用，拖曳或直接Worker指令亦不能繞過。
- 上方保留完整 1～10 階寶石列，工具頁籤位置與其他工具一致。點擊上方某階寶石即可鑲入目前選中孔，或由上方拖曳到符合限制且未滿的孔位。合法拖曳目標顯示綠框，不符合的孔位顯示紅框。
- 拖曳預覽只顯示該階寶石icon，透明背景、維持原畫面尺寸、游標位於中心；不帶卡片外框、階級、能力或庫存文字，拖曳開始時收起懸浮說明。放下或取消後清理預覽。
- 不符最低階、該階未持有或選中孔已滿時，上方對應寶石會置灰停用，不能點擊或啟動拖曳；放開時仍核對最新庫存與孔位容量。空分類也保留十階佔位，避免頁籤跳動。
- 右側依序只顯示「類型＋最低階寶石」、「等級 Lv.X」、「獲得相鄰寶石能力+X%」、直列鑲孔、「升級鑲孔」及「共鳴效果：」綠字清單。移除孔位編號／中心外圈／容量／上限／常駐花費與操作說明；空位顯示「鑲孔」，已鑲欄加寬至資訊區可用寬度，保持原38px格高與32px圖示，旁邊以小字分兩行顯示寶石名稱及本身能力；點擊仍逐顆取下，完整名稱與能力亦可懸停查看。
- 升級所需金幣與材料及目前持有量改放按鈕Tooltip，不足、滿級與中央鎖定原因亦在提示中；禁用時仍可懸停查看，鍵盤可聚焦按鈕外層查看。右側「共鳴效果」只合計所選孔獲得的相鄰額外加成，不含自身寶石能力、其他孔與整盤總合；同類能力合併，未計全域鑲嵌效率。空孔、0級、沒有相鄰寶石或中央未解鎖時清單為空；鑲入、取下與升級即時更新。
- 共鳴說明i位於資訊區左外側、獨立於資訊捲動區；較窄版面將資訊排至盤面下方，i仍留在資訊左側，不擋住文字。
- i的說明為三行：「把寶石鑲入共鳴鑲孔中以獲取寶石能力。」「升級鑲孔可獲得相鄰寶石效果的額外加成。」「中央區將在周圍六大區鑲孔都升至10級時解鎖。」
- 一般寶石工具的分類偏好獨立保留；切回合成等工具時，上方十階列恢復選擇階級的操作。
- 窄畫面將孔位詳情排在盤面下方，可在工坊面板內捲動查看。

## 共鳴盤外觀與素材

- 六邊形底板與孔位共用 SVG 座標，顯示範圍收去母圖外透明留白，等比放大至接近盤面上下邊緣並保留安全距離；獨立欄位避免遮到右側文字，窄畫面依相同比例堆疊。盤面不顯示外圍區域名稱，孔位、水晶切面、寶石與選中框共同等比放大至底板內緣；區域資訊保留在孔位無障礙標籤與右側所選孔資訊。選中框仍在最上層，以完整 5px 亮黃白框提示。
- 選孔不顯示瀏覽器原生白色矩形外框，沿用六角選中與鍵盤焦點提示。孔內只顯示非零的強化等級數字，不加Lv，0級留白，最低寶石階級改由右側需求與左側孔位說明提示。單顆維持原縮圖，多顆按實際顆數分區並各顯示一顆，兩顆左右對分，六顆六個扇區；不顯示顆數。各區塊共用原鑲孔操作，右側可逐顆取下；空孔強化數字置中，已鑲多於兩顆時數字縮小置中。
- 底板、切面、寶石圖與文字不攔截操作；每孔保留完整透明命中面，沿用原本的選孔、點擊／拖曳鑲嵌、取下與升級指令。較窄的工坊（容器寬度不超過 650px）將詳情排到下方，避免盤面被擠小。
- `images/ui/gem-resonance/hex-backplate.png` 為本聊天以內建 imagegen 自製、經使用者確認的透明 PNG，1254×1254；本次直接接入已確認母圖，沒有重新作圖或改圖。水晶切面由 `js/ui-gem-resonance.js` 的 SVG 程序繪製，沒有引入外部第三方素材。
- 母圖、來源與匯出紀錄保存在素材庫相對路徑 `codex-authored/gem-resonance/`；`node tools/gem-resonance/export-source.cjs --apply` 原樣匯出，`--check` 核對母圖／紀錄／遊戲 SHA256。沿既有 `vfx-library-root.cjs` 解析本機素材庫位置，不把本機絕對路徑寫入程式。

## 程式結構

- `js/gem_resonance_data.js`：配置表資料（兩端共載）。
- `js/gem_resonance.js`：版面／相鄰／屬性貢獻（純函式）＋Worker 端指令實作。
- `js/formula.js` `computeStats`：在裝備鑲嵌寶石之後併入 `resonanceEntries`。
- `js/worker/protocol.js` v53：`gem.resonanceSocket`／`gem.resonanceUnsocket`／`gem.resonanceUpgrade`；gems 面板新增 `resonance`。
- 存檔：`G.player.resonance = { holes: { '區域:孔': { gems: [{type, level}], lv } } }`；舊存檔由 `mergeDefaults` 補空表，`save.js` 載入時整理。**不需要 Migration**。
- `js/ui-gem-resonance.js`＋`css/gems.css`：SVG 盤面與右側操作面板。

## 建議驗證項目（給 Antigravity）

- 左側只切類型／不可拖曳鑲入，上方十階列點擊／拖曳鑲入；階級不足／零庫存／滿孔置灰，取下回庫存，切工具還原分類與選階級操作。
- 合成／共鳴切換、選孔、選類型與空分類時，上方十階列和工具頁籤位置保持一致。
- 各區點孔：種類限制、右側最低階需求、容量（中心孔 2／6）；孔內數字只有強化等級且0級留白。
- 中央鎖定／最後一個外圍孔9→10級解鎖；鎖定時鑲入／升級／拖放／直接Worker指令皆拒絕且不扣資源，既有中央寶石可取下、能力停用；解鎖後操作與能力恢復。
- 鑲嵌後屬性面板數值上升；升級後相鄰孔寶石的加成依 3%／級增加、10 級封頂 30%；取下後屬性回落、孔等級保留。
- 存檔重新整理後孔位與孔等級還在；舊存檔（沒有共鳴資料）可正常載入。
- BOSS 戰中鑲嵌被拒、升級可用；寶石鑲嵌效率（威能「寶石共鳴」、戒指／項鍊詞條）會放大共鳴能力。
- 手機窄螢幕下盤面與右側面板折行不重疊。
