# 神祕商人

商店等級、價格、商品權重與機率配置在 `config/Excel/Store.xlsx`。儲存並關閉 Excel 後執行根目錄的「套用參數.bat」，會匯出 Store.csv 並套用到遊戲。

## 邀請券與進入

- 每次封魔塔BOSS勝利獨立判定掉落1張；「邀請券掉落率」使用百分比，初值10，0停掉、100必掉，不受掉寶率影響。
- 持有至少1張時封魔塔上方入口高亮閃爍、主頁籤顯示驚嘆號。無券時置灰，tips說明所需條件。
- 每次召喚進店時扣 1 張並生成商品，是否購買不影響召喚費用。同一會話內重複送出開啟指令不重扣。返回封魔塔、切換頁籤或重載結束會話。
- 手動刷新每次扣 1 張，券不足時保留現有商品。舊的金幣刷新價格與定時自動換貨已取消。商店升級仍以金幣付費並補上新等級商品。
- 券在商人界面顯示，不列置頂材料。新局／舊存檔缺欄皆為0，無免費補券。內測本機GM可用 `invite 5` 發5張供測試。

## 商品調整

| Store列 | 用途 |
| --- | --- |
| 寶石／裝備／符文／遺物權重 | 正權重且有供應器的類別先各有一格，其餘格依相對權重抽取。0 關閉該類。實際商品數依商店等級抽取，上限 40 件。介面固定 10 欄、4 列，餘位保留空格。 |
| 裝備最低／最高品質 | RARITIES索引0～11。品質上限再取「已通關最高層塔BOSS可掉落的最高品質」與配置上限的較小者。最低品質高於進度上限時降為上限，避免生成越級裝備。未通關以第1層為基準。 |
| 裝備等級倍率 | 玩家當前等級乘倍率，沿原裝備等級分段。 |
| 裝備價格基數 | 金幣價＝基數×裝備等級×(品質索引+1)。 |
| 裝備太古詞條機率 | 每個參數格填 `條數=機率%`，例如參數a=`0=75`、b=`3=20`、c=`4=5`。條數不可重複，機率總和必須100%。可填到參數l；未用格留空或填0。抽中條數超過該件實際詞條數時，依原生成器截至詞條總數，不額外增加詞條。只影響商人裝備，野外／塔BOSS／熔爐規則不變。 |
| 符文最低／最高階級 | 在正式RUNES中篩選階級，區間內均勻抽樣。 |
| 符文價格基數／指數 | 金幣價＝基數×符文階級^指數，四捨五入。 |
| 遺物權重／價格／階級 | 商人遺物供應器的預留設定。 |

商品生成時確定完整裝備實體與價格，購買不重擲。裝備先檢查背包空間；滿包拒絕且不扣款，成功直接入背包，不經自動穿戴／熔解。全買會略過無法購買的項目並繼續其他商品。商品sold旗標保留至下一次刷新／召喚。

## 擴充接口與存檔

`MYSTERY_MERCHANT_PROVIDERS` 位於 item.js，以類別提供 `available()`、`roll(shopLevel)`、`canBuy(item)`、`grant(item)`。roll回傳 `{kind,price,sold,...payload}`；canBuy回傳錯誤文字或null，grant完成正式庫存發放。未註冊的relic不進商品池；實作遺物時接入正式庫存並擴充UI的商品呈現。

沿用 `player.gemShop` 保存等級與庫存，券為 `player.consumables.mystery_invitation`。`MYSTERY_MERCHANT_OPEN` 為 Worker 暫態，載入後須再次召喚。Worker 協議 v78 以 `tower.merchant={active,tickets,shop}` 提供會話與庫存，`gem.shopBuy`、`gem.shopBuyAll`、`gem.shopRefresh`、`gem.shopUpgrade` 均要求有效會話。
