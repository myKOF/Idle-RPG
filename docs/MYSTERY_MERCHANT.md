# 神祕商人

商店等級、價格、商品權重與機率配置在 `config/Excel/Store.xlsx`。儲存並關閉 Excel 後執行根目錄的「套用參數.bat」，會匯出 Store.csv 並套用到遊戲。

## 邀請券與進入

- 每次封魔塔BOSS勝利獨立判定掉落1張；「邀請券掉落率」使用百分比，初值10，0停掉、100必掉，不受掉寶率影響。
- 持有至少1張時封魔塔上方入口高亮閃爍、主頁籤顯示驚嘆號。無券時置灰，tips說明所需條件。
- 每次召喚進店時扣 1 張並生成商品，是否購買不影響召喚費用。同一會話內重複送出開啟指令不重扣。返回封魔塔、切換頁籤或重載結束會話。
- 手動刷新每次扣 1 張，券不足時保留現有商品。舊的金幣刷新價格與定時自動換貨已取消。商店升級仍以金幣付費並補上新等級商品。
- 券在商人界面顯示，不列置頂材料。新局／舊存檔缺欄皆為0，無免費補券。內測本機GM可用 `invite 5` 發5張供測試。

## 商品調整

Store 後方各有 20 列逐級設定，與寶石表使用同一種填法。找到要改的 `商店 Lv.N`，每個參數格填一組 `項目=機率%`，例如 `19=70` 和 `20=30`。同列項目不可重複，機率加總為 100。全列留白或填補位數字 `0` 時沿用通用設定。右側新增的 `參數m` 至 `參數ag` 可容納 33 個符文階級。

| Store列 | 用途 |
| --- | --- |
| 8-商人刷出類別 | 例如 `寶石=50`、`裝備=30`、`符文=20`。可供應且機率大於 0 的類別先各有一格，其餘依相對機率抽取。要關閉整個等級的商品，可將所有類別明確填為 `類別=0`。商品數沿用逐級數量表，上限 40 件。 |
| 8-商人裝備品質 | 填 `品質索引=機率%`，索引 0～11。先按裝備最低／最高品質與已通關最高層塔 BOSS 的品質上限過濾，再依剩餘機率抽取。若候選全數越界，改為可取得的上限。未通關以第 1 層為基準。 |
| 8-商人裝備部位 | 例如 `武器=60`、`戒指=40`。另可填頭盔、肩甲、胸甲、腰帶、手套、護腕、腿甲、靴子或項鍊。預設沿用等機率。 |
| 8-商人裝備太古 | 例如 `0=75`、`3=20`、`4=5`。若抽中條數超過該件裝備的詞條數，取實際詞條數。 |
| 8-商人符文階級 | 1～33 階各代表一種符文。例如 `33=100` 只刷終焉符文。留白時按通用的符文最低／最高階級等機率抽取。 |
| 8-商人遺物階級 | 預留給遺物供應器的逐級設定。 |
| 裝備等級倍率 | 玩家當前等級乘倍率，沿原裝備等級分段。 |
| 裝備價格基數 | 金幣價＝基數×裝備等級×(品質索引+1)。 |
| 符文價格基數／指數 | 金幣價＝基數×符文階級^指數，四捨五入。 |

逐級預設分布沿用原通用設定。遺物提供的高階寶石、裝備及符文加成會套在可抽中的候選權重上。

商品生成時確定完整裝備實體與價格，購買不重擲。裝備先檢查背包空間；滿包拒絕且不扣款，成功直接入背包，不經自動穿戴／熔解。全買會略過無法購買的項目並繼續其他商品。商品sold旗標保留至下一次刷新／召喚。

## 擴充接口與存檔

`MYSTERY_MERCHANT_PROVIDERS` 位於 item.js，以類別提供 `available(shopLevel)`、`roll(shopLevel)`、`canBuy(item)`、`grant(item)`。roll回傳 `{kind,price,sold,...payload}`，canBuy回傳錯誤文字或null，grant完成正式庫存發放。遺物供應器接入時可用 `merchantLevelPairs(MERCHANT_RELIC_TIER_TABLE, shopLevel)` 讀該級機率，並接入正式庫存和商品呈現。

沿用 `player.gemShop` 保存等級與庫存，券為 `player.consumables.mystery_invitation`。`MYSTERY_MERCHANT_OPEN` 為 Worker 暫態，載入後須再次召喚。Worker 協議 v78 以 `tower.merchant={active,tickets,shop}` 提供會話與庫存，`gem.shopBuy`、`gem.shopBuyAll`、`gem.shopRefresh`、`gem.shopUpgrade` 均要求有效會話。
