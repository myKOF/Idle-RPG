原型為本專案的荒原序章分鏡 `codex-authored/intro-dark-fantasy-20261105/originals/desolate-human-world.png`，使用者提供的兩張截圖供比對構圖及標記動態位置。2026-11-06 確認 RPG Mote Studio 可存取。這次需要保留高解析寫實繪景、重繪旗布後方及輸出透明布料，使用內建 ImageGen 以原畫編修。保留兩張生成母圖、實際提示詞及 Canvas 動畫來源於 Effects-Materials 的 `codex-authored/start-menu-wasteland-20261106`。

- 遊戲使用 `battlefield-atmosphere.webp`（1672 × 941）。2026-11-11 以內建 ImageGen 局部編修專案原畫，保留拱門輪廓、旗桿與前景位置。右上山脈加上暗紅裂隙與濃煙，右側廢拱門下加入一道天光。使用者截圖供構圖與氛圍參考。RPG Mote Studio 可連線，這組素材需要寫實繪景局部重繪與透明立體金屬字，採用 ImageGen。原始編修稿與完整提示詞 `ATMOSPHERE_PROMPTS.json` 存在同一素材庫套件。
- `battlefield.webp` 是 1672 × 941 的初版無字繪景。岩壁、拱門、遺骸、武器及旗桿的座標仍為新版場景基準，旗布和鬼火獨立播放。
- `cloth-atlas.webp` 是 1774 × 887 的透明圖集。上半為破旗，下半為窄布條，場景以旗桿為錨點做連續的網格變形。
- 初版底圖及布料保留母圖尺寸及透明資料，Pillow WebP method 6，品質依序 90、87。新版母圖為 1671 × 941，等幅對齊場景座標後輸出品質 90 的 WebP。雲、鬼火、貼地風沙與遠山火光在 Canvas 合成。

以 `node tools/intro/sync-start-menu.cjs --archive` 保存背景動畫來源及 SHA；`--apply` 將素材庫的匯出檔同步到本目錄；`--check` 核對來源、動畫程式與遊戲匯出。

## 陣風與遠山戰火

左上雲帶獨立循環，中央拱門內的雲霧沿原畫遮罩以 125% 速度移動。中段霧帶及左下局部霧層各以每秒 14 和 7.5 個底圖像素向左飄移，沙粒、沙霧與稀疏餘燼同樣由右往左。破旗沿原有旗桿錨點隨陣風平滑變形。右上三段火線取新版底圖的暖色做局部遮罩，疊上光暈、火尖與火星。最遠處降低亮度以保留距離感。

左下額外陣風沿羽化遮罩消散。局部陣風仍採加倍的沙粒與霧束，霧層在陣風間隙持續流動。鎧甲胸縫、斷劍護手與右側肋骨錨定青綠魂火，疊加柔暈、煙絲與上浮光點，遠處殘骸則帶較弱的魂火。

## 拱門遠空紅色閃電

中央拱門後方偶發紅色落雷。每次由程序產生主幹、七道分叉及更細的末梢，疊上細亮芯、紅色光暈與雲內散光。一般模式有三次短促放電及較慢消退的餘光，減少動態採一次柔和亮起。天空遮罩共用拱門和遠景輪廓，雲霧在閃電前方持續流動。首個事件在可見畫面開始後約 2.8–6.2 秒，後續兩次事件的間隔約 8.1–20.1 秒。

由背景的單一畫面時鐘管理，隱藏分頁或選單時暫停，重新顯示後續播，卸載時回收事件。這些程序效果與分鏡共用畫幅，不需另載序列貼圖。

## 中央拱門聖光

四束近白色光從拱頂後的雲縫向右下散開，彼此錯開明暗與角度，在遠方霧層逐漸消散。光束與雲端散光由 Canvas 預先繪製，每幀在拱門內側的羽化遮罩合成，石柱保留遮擋，前方仍有地平霧帶。減少動態時放慢明暗變化並降低角度擺幅，沿用背景的可見性與卸載機制。

## 接入開始選單

由選單載入 `<script src="js/start-menu-background.js?v=1.0.8"></script>`，並在選單背景的定位容器掛載。

```js
const backdrop = StartMenuBackground.mount(document.getElementById('start-menu'));
// backdrop.ready 是 Promise<boolean>，底圖及布料可用時為 true。
// 離開選單或拆卸容器時再呼叫 backdrop.destroy()。可重複呼叫。
```

容器應有定位與自己的堆疊環境，例如 `position: fixed; isolation: isolate`。背景佔滿容器，z-index 為 0。選單卡片須有較高層級。可在序章播放時掛載至隱藏的選單容器以提前載入素材。背景不攔截指標、不管理焦點與遊戲流程。縮窄視窗時以置中的滿版裁切維持拱門，兩側物件可能超出可視區。減少動態偏好下以一般模式 65% 的速度播放，旗布擺幅和風沙不透明度同樣降低。隱藏分頁或選單時停止計時。素材載入失敗時保留已可用的背景層，選單可照常使用。
