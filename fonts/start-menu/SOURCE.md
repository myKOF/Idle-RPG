# 開始選單字型

依使用者提供的三層字體參考，開始選單的按鈕屬第二層。瀏覽器使用本機 WOFF2。各字型的授權原文置於同一目錄。

| 字型檔 | 來源與範圍 | 授權 |
| --- | --- | --- |
| `cinzel-bold.woff2` | [Google Fonts Cinzel](https://fonts.googleapis.com/css2?family=Cinzel:wght@700&display=swap) 的 700 字重 Latin WOFF2 | [SIL OFL 1.1](OFL-Cinzel.txt)，The Cinzel Project Authors |
| `noto-serif-tc-bold.woff2` | [Google Fonts Noto Serif TC](https://github.com/google/fonts/tree/main/ofl/notoseriftc) 的 700 字重 WOFF2，透過 Google Fonts CSS API 的 `text=` 參數保留目前選單按鈕的 25 個不同繁中字 | [SIL OFL 1.1](OFL-Noto-Serif-TC.txt)，授權原文依 Google Fonts 上游 |

繁中字集為 `入噩回困夢存定就式成戲新模檔煉獄繼續設載返遊開離難`，取自 String 表的 1947、2228、2421–2428 與 2431。字集外的文字使用系統襯線備援。遊戲檔與 Effects-Materials 的 `third-party/google-fonts/start-menu-20261106` 保存相同的 Google Fonts WOFF2 位元組與授權。
