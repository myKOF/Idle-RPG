# 地圖背景音樂

Zones.xlsx「地圖」的 BGM 欄填寫專案相對路徑，留空表示該地圖沒有配樂。經 Excel → CSV → config_tables 套用至 ZONES.bgm。場景依 Worker 的 zone／towerActive 權威快照切換；同地圖換關不重新起播，離開該地圖或進入封魔塔即停止。沿用音樂音量及全體靜音，分頁隱藏時持續循環，離開網頁時暫停。瀏覽器限制自動播放時，在首次真實操作後起播。
