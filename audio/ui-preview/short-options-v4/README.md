# 清晰短促UI音 — 觸碰／點擊各五款

使用者要求重做、不限材質，以清晰短促為主。此版只有試聽候選，10款沒有接入遊戲；先前方案及現行音效均保留。

| --- | --- | --- |
| H1 | 觸碰 | 乾淨短嗒：乾燥短tick，微量中頻支撐。 |
| H2 | 觸碰 | 柔和短啵：圓潤快速下滑的短音。 |
| H3 | 觸碰 | 俐落輕刷：緊密、短促的氣流切音。 |
| H4 | 觸碰 | 清亮短音：乾淨明亮的單音，沒有鈴聲長尾。 |
| H5 | 觸碰 | 清脆卡榫：短小雙瞬態，呈現扣合感。 |
| C1 | 點擊 | 實體按鍵：接觸短響與中低頻按壓。 |

觸碰50～70ms、點擊65～95ms，皆短於0.11秒。分類內以RMS目標及峰值上限控制音量，點擊略強於觸碰，不以低音量掩蓋音色差異；沒有加長殘響。每款獨立WAV，hover-sampler.wav依H1→H5、click-sampler.wav依C1→C5，各款連續播放兩次，項目間隔0.75秒；manifest附精確時間點。名稱為設計意圖，聽感由使用者確認。

全部Codex原創程序合成（固定種子噪音、振盪器、包絡），不使用外部素材、錄音、取樣庫或參考音檔。48kHz／16-bit立體聲PCM，置中、起尾淡化、無削波。唯一可編輯來源tools/audio/ui-short-options.cjs，--apply重產、--check驗兩庫SHA；素材庫codex-authored/ui-short-options-20261104-v4先保存母檔、來源與說明，再原樣匯出至本資料夾。
